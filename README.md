# DA_MAY_2026 — курс по Data Analytics и системной аналитике

**Это курс по Data Analytics и системной аналитике.**

Репозиторий содержит последовательный учебный маршрут по функциональному программированию на Python, работе в Jupyter Notebook, SQL, MySQL, `pandas`, языку R, R Markdown, Git, GitHub, Docker Compose, сетевым протоколам, API, проектированию ИИ-ассистентов и агентной работе с кодовой базой.

Материалы построены по принципу «от базовых упражнений к воспроизводимому аналитическому и системному решению»: сначала слушатель осваивает функциональный стиль программирования на Python и работу в Jupyter Notebook, затем SQL и аналитические библиотеки, после этого выполняет проекты на Python и R, изучает полный аналитический пайплайн, основы системного взаимодействия, системные инструкции для ИИ и агентный сценарий разработки.

## Быстрая навигация

**Папка:** [`item_5`](./item_5)

- [`employees_data.json`](./item_5/employees_data.json) — тот же набор данных в формате JSON для практики чтения полуструктурированных данных.
- [`employees_data.xlsx`](./item_5/employees_data.xlsx) — тот же набор данных в формате Excel для практики импорта электронных таблиц.

### Тематическая карта последовательных учебных скриптов

> Описания ниже используются как навигационная карта учебной последовательности. Для технической документации конкретных операций следует дополнительно сверять формулировку с кодом соответствующего `.R`-файла.

- [`part1.R`](./item_5/part1.R) — знакомство с R: структура скрипта, комментарии, выполнение команд и базовые арифметические операции.
- [`part2.R`](./item_5/part2.R) — переменные и оператор присваивания: сохранение значений, переиспользование результатов и правила именования объектов.
- [`part3.R`](./item_5/part3.R) — базовые типы данных и преобразование типов: числа, строки, логические значения и проверка структуры объекта.
- [`part4.R`](./item_5/part4.R) — векторы и векторизованные операции: создание последовательностей, вычисления сразу над набором значений и базовые агрегаты.

- [`part8.R`](./item_5/part8.R) — факторы и категориальные признаки: хранение категорий, уровни факторов и подготовка категориальных данных к анализу.

- [`part12.R`](./item_5/part12.R) — пользовательские функции: параметры, возвращаемые значения и вынесение повторяющейся логики в переиспользуемый код.

- [`part14.R`](./item_5/part14.R) — описательная статистика: минимум, максимум, среднее, медиана, квантили, разброс и первичное описание распределений.

1. **Item 1:** освоить Jupyter Notebook и базовые принципы функционального программирования на Python.

## Три сценария работы с ИИ в рамках репозитория

### 1. Пользовательский сценарий

### 3. Агентный сценарий

ИИ-агент получает доступ к разрешённым инструментам и выполняет действия в репозитории. Правила задаются через `AGENTS.md` и связанные документы. Практический пример с OpenCode находится в `item_10`.
