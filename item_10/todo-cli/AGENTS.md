# AGENTS.md — Инструкции для разработчика

## Цель проекта

Консольное приложение для управления списком задач (Todo-список).
Приложение работает с JSON-файлом `todo.json`, предоставляет команды
`add`, `list`, `done`, `delete` через argparse.

## Технологии

- Python 3.10+
- Только стандартная библиотека
- argparse — разбор аргументов командной строки
- json — хранение данных
- unittest — тестирование

## Структура проекта

```
src/cli.py        — точка входа, разбор аргументов CLI
src/core.py       — бизнес-логика: добавление, удаление, завершение задач
src/storage.py    — чтение/запись todo.json
src/models.py     — тип данных задачи (dataclass)
tests/             — тесты модулей
```

## Команды приложения

| Команда | Описание |
|---------|----------|
| `python -m src.cli add "Текст задачи"` | Добавить задачу |
| `python -m src.cli list` | Показать все задачи |
| `python -m src.cli done <id>` | Отметить задачу как выполненную |
| `python -m src.cli delete <id>` | Удалить задачу |

## Правила разработки

1. Перед созданием или изменением Python-кода **обязательно** прочитать
   файл `docs/python-style.md`.
2. Этот файл (`AGENTS.md`) имеет **приоритет** над `docs/python-style.md`.
   При противоречии — следовать правилам из `AGENTS.md`.
3. Использовать только стандартную библиотеку Python.
4. Все изменения сопровождать тестами в `tests/`.
5. После каждого изменения запускать `python -m unittest discover tests`.

## Правила тестирования

- Все тесты писать в `tests/` с префиксом `test_`.
- Покрывать модули `core.py` и `storage.py` тестами.
- Тесты CLI проверять через `subprocess.run` или `unittest.mock`.
- Тесты должны проходить после каждого изменения.
- Запуск: `python -m unittest discover tests`.

## Приоритет

1. `AGENTS.md` — главный файл инструкций.
2. `docs/python-style.md` — вспомогательные правила стиля кода.
