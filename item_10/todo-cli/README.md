# todo-cli

Консольное Todo-приложение на Python для управления списком задач.

## Требования

- Python 3.10+
- Только стандартная библиотека

## Использование

```bash
# Добавить задачу
python todo.py add "Купить молоко"

# Показать все задачи
python todo.py list

# Отметить задачу как выполненную
python todo.py done 1

# Удалить задачу
python todo.py delete 1
```

## Хранение данных

Задачи хранятся в файле `todo.json` в текущей директории.
Файл создаётся автоматически при первом запуске.
