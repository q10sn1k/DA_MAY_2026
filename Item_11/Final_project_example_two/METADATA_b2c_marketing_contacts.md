# Метаданные синтетического датасета B2C-маркетинга

## 1. Назначение

Учебный CSV предназначен для освоения полного аналитического пайплайна на упрощённом B2C-маркетинговом примере. Данные полностью синтетические и не описывают реальных людей, рекламные кабинеты или компании.

## 2. Технические характеристики исходного файла

| Параметр | Значение |
|---|---|
| Файл | `b2c_marketing_contacts_10000.csv` |
| Формат | CSV с заголовком |
| Кодировка | UTF-8 with BOM |
| Разделитель | запятая |
| Строк | 10 000 |
| Столбцов | 10 |
| Период | 2025-01-01 — 2025-12-31 |
| Grain | один маркетинговый контакт |
| Основной ключ | `contact_id` после удаления полных дублей |
| Персональные данные | отсутствуют |

## 3. Как понимать единицу наблюдения

Одна строка описывает один маркетинговый контакт с потребителем. Это может быть отправка email, показ сообщения в социальной сети, поисковой или медийной рекламе либо Push-коммуникация.

Строка не описывает уникального клиента. В исходной модели отсутствует идентификатор человека, поэтому повторные контакты одного потребителя нельзя объединить в путь клиента.

## 4. Словарь десяти полей

| Поле | Тип после очистки | Описание |
|---|---|---|
| `contact_id` | string | идентификатор маркетингового контакта |
| `contact_date` | datetime | дата контакта |
| `channel` | category/string | маркетинговый канал |
| `campaign_type` | category/string | тип кампании |
| `customer_segment` | category/string | Новый, Повторный или Лояльный |
| `device_type` | category/string | тип устройства |
| `ad_cost_rub` | float | стоимость контакта, руб. |
| `clicked` | integer | 1 — был клик, 0 — клика не было |
| `converted` | integer | 1 — произошла покупка, 0 — покупки не было |
| `revenue_rub` | float | выручка после контакта, руб. |

## 5. Основные бизнес-правила учебной модели

1. `contact_id` уникален после удаления полных дублей.
2. `clicked` и `converted` принимают только 0 или 1.
3. Покупка возможна только после клика.
4. Если покупки нет, `revenue_rub = 0`.
5. Если покупка есть, выручка положительна.
6. Стоимость контакта находится в диапазоне от 0.01 до 500 рублей.

## 6. Производные маркетинговые показатели

| Показатель | Формула | Смысл |
|---|---|---|
| CTR | клики / контакты | доля контактов, завершившихся кликом |
| Конверсия | покупки / контакты | доля контактов, завершившихся покупкой |
| Конверсия после клика | покупки / клики | доля кликов, завершившихся покупкой |
| ROAS | выручка / рекламные расходы | выручка на один рубль рекламного расхода |
| CPA | рекламные расходы / покупки | стоимость одной покупки |

ROAS не равен прибыли или рентабельности: в датасете отсутствуют себестоимость товара, возвраты, налоги, логистика и операционные расходы.

## 7. Намеренно добавленные учебные дефекты

- 25 полных дубликатов;
- смешанные и невозможные форматы дат;
- варианты регистра и пробелы в категориях;
- пропуски канала, стоимости и выручки;
- некорректные значения бинарных признаков;
- отрицательные и аномально большие денежные значения;
- покупки без клика;
- положительная выручка без покупки.

## 9. Ограничения интерпретации

- Одна строка описывает контакт, а не уникального клиента.
- Атрибуция упрощена до одного контакта и одного клика.
- Покупки без клика исключены правилами модели, хотя реальные системы могут использовать view-through attribution.
- Статистическая связь канала и покупки не доказывает причинность.
- Синтетические закономерности нельзя переносить на реальный рынок.
- Датасет не содержит персональных данных.

## 10. Воспроизводимость

Notebook `b2c_marketing_analysis.ipynb` читает исходный CSV, выполняет очистку, рассчитывает показатели, создаёт очищенный CSV и сохраняет итоговый дашборд. Для проверки следует выполнить все ячейки сверху вниз и получить сообщение `QA PASSED`.
