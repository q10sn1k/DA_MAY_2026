# Метаданные: датасет клиентов для кластеризации

## Назначение

Учебная версия того же набора клиентов для обучения без учителя. Из файла удалены обе целевые колонки, чтобы алгоритм кластеризации не видел готовые ответы.

## Технические характеристики

- Файл: `ml_customers_clustering_800.csv`
- Строк: 800
- Столбцов: 8
- Формат: CSV
- Кодировка: UTF-8 with BOM
- Grain: один синтетический клиент
- Ключ: `customer_id`
- Пропуски: отсутствуют
- Полные дубликаты: отсутствуют

## Словарь полей

| Поле | Тип | Использование | Описание |
|---|---|---|---|
| customer_id | string | только связь с результатом | технический ID, не участвует в K-Means |
| age | integer | признак | возраст, лет |
| monthly_income_rub | integer | признак | условный ежемесячный доход, руб. |
| visits_per_month | integer | признак | число посещений в месяц |
| avg_session_minutes | float | признак | средняя длительность сессии, минут |
| support_requests_3m | integer | признак | обращения в поддержку за 3 месяца |
| purchases_last_3m | integer | признак | покупки за 3 месяца |
| days_since_last_purchase | integer | признак | дней с последней покупки |

## Отличие от supervised-версии

Удалены:

- `monthly_spend_rub`;
- `premium_buyer`.

Это предотвращает использование готовых ответов при кластеризации.

## Ограничения

- Кластеры не являются истинными классами.
- Номера кластеров не имеют естественного порядка.
- Полезность групп должна подтверждаться интерпретацией и проверкой на новых данных.
