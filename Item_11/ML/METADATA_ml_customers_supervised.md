# Метаданные: supervised-датасет клиентов

## Назначение

Учебный синтетический датасет для первых примеров регрессии и классификации. Данные не относятся к реальным людям.

## Технические характеристики

- Файл: `ml_customers_supervised_800.csv`
- Строк: 800
- Столбцов: 10
- Формат: CSV
- Кодировка: UTF-8 with BOM
- Grain: один синтетический клиент
- Ключ: `customer_id`
- Пропуски: отсутствуют
- Полные дубликаты: отсутствуют

## Словарь полей

| Поле | Тип | Роль | Описание |
|---|---|---|---|
| customer_id | string | идентификатор | технический ID клиента; не используется как признак |
| age | integer | признак | возраст, лет |
| monthly_income_rub | integer | признак | условный ежемесячный доход, руб. |
| visits_per_month | integer | признак | число посещений сервиса за месяц |
| avg_session_minutes | float | признак | средняя длительность сессии, минут |
| support_requests_3m | integer | признак | обращения в поддержку за 3 месяца |
| purchases_last_3m | integer | признак | покупки за 3 месяца |
| days_since_last_purchase | integer | признак | дней с последней покупки |
| monthly_spend_rub | float | target регрессии | расходы клиента за месяц, руб. |
| premium_buyer | integer 0/1 | target классификации | 1 — премиальный покупатель, 0 — нет |

## Бизнес-правила учебной модели

- `customer_id` уникален.
- `premium_buyer` принимает только 0 или 1.
- Все числовые поля заполнены.
- Данные синтетические и предназначены только для обучения.

## Ограничения

- Формулы генерации специально упрощены.
- Высокое качество моделей на этом наборе не переносится на реальные данные.
- Датасет не следует использовать для решений о людях.
