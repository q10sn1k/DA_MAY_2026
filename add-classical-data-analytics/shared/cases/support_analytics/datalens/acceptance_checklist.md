- [ ] Для каждой страницы указан отдельный датасет и его гранулярность.
- [ ] Источники загружены без изменения кодировки и типов дат.

- [ ] Селектор периода меняет все связанные операционные чарты.

- [ ] Сценарий меняет только прогнозные объекты.
- [ ] Таблица риска сортируется по вероятности.
- [ ] Navigator позволяет менять окно временного ряда.

## Визуальная честность

- [ ] Оси и масштабы не преувеличивают различия.
- [ ] Проценты имеют одинаковый формат.
- [ ] Размер и цвет на карте кодируют разные показатели.
- [ ] Точечный прогноз визуально отделён от границ интервала.
- [ ] Цветовая шкала риска имеет легенду.
- [ ] Для маленьких сегментов отображается support или предупреждение.
