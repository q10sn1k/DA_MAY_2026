# Карта полей и чартов

## Карта регионов

| Секция | Поле |
|---|---|
| Тип | Карта → точечный слой |
| Точки | `region_point = GEOPOINT([latitude], [longitude])` |
| Размер | `SUM([tickets_count])` |
| Цвет | вычисляемая доля SLA |
| Тултип | city_name, macro_region, team_name, обращения, SLA rate, AVG(resolution_min) |
| Фильтр | `geo_available = 1` |

Контрольный срез за июнь 2026:

- Москва — 380 обращений;
- Екатеринбург — около 37,22% нарушений;
- Казань — около 36,53%;
- на карте присутствуют восемь городов.

## Динамика

| Секция | Поле |
|---|---|
| X | `created_date` |
| Y | `SUM([tickets_count])` |
| Цвет | при необходимости `channel` |
| Navigator | включить для длинного периода |

## Прогноз и интервал

| Секция | Поле |
|---|---|
| X | `date` |
| Y | `forecast`, `lower_80`, `upper_80` |
| Цвет | `scenario` |
| Фильтр | один выбранный сценарий |
| Navigator | включить |

Если текущий тип чарта не поддерживает заливку диапазона, отобразите нижнюю и верхнюю границы отдельными линиями и явно подпишите их.

## Таблица рискованных обращений

| Поле | Назначение |
|---|---|
| `ticket_id` | идентификатор |
| `created_date` | дата |
| `city_name` | региональный контекст |
| `team_name` | ответственная команда |
| `priority` | приоритет |
| `risk_probability` | откалиброванная вероятность |
| `risk_class` | решение по рабочему порогу |

Сортировка: `risk_probability` по убыванию. Фильтр по умолчанию: `risk_class = 1`.

## Качество данных

Источники: `data_validation_gate.csv` и `load_quality_summary.csv`.

- индикатор числа критических FAIL;
- столбчатая диаграмма проверок по статусам;
- таблица всех FAIL и WARNING;
- таблица свежести загрузок;
- диаграмма отклонённых строк по источникам.
