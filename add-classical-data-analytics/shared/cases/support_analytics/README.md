# Практический кейс аналитики службы поддержки

## Что вы создадите

К завершению работы у вас будут:

- отчёт качества и решение validation gate;
- очищенная таблица обращений;
- первичные визуализации;
- точечный и интервальный прогнозы на 14 дней;
- сценарии потребности в операторах;
- профили кластеров команд;
- модель риска SLA;
- откалиброванные вероятности и обоснованный порог;
- анализ ошибок по сегментам;
- BI-витрина и управленческая записка.

## Быстрый старт

1. Полностью распакуйте архив.
2. Откройте терминал в корне проекта.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите Jupyter: `jupyter notebook`.
5. Работайте только с файлами из `notebooks/student/`.
6. Не изменяйте файлы в `data/raw/` вручную.

## Порядок выполнения

1. Откройте `00_data_validation_gate_student.ipynb` и выполните raw gate.
2. Выполните `01_data_quality_eda_student.ipynb`.
3. Вернитесь в notebook `00` и выполните clean gate.
4. Последовательно выполните notebooks `02`, `02b`, `03`, `04`, `04b`, `04c` и `05`.
5. Для сборки дашборда используйте папку `datalens/`.

Во время очного семинара расширенные notebooks `02b`, `04b` и `04c` могут выполняться в управляемом режиме вместе с преподавателем. Для итоговой работы заполните их полностью.

## Где лежат файлы

- исходные данные: `data/raw/`;
- notebooks: `notebooks/student/`;
- ваши результаты: `outputs/`;
- графики: `outputs/charts/`;
- описание полей: `docs/data_dictionary.md`;
- правила качества: `docs/data_quality_rules.md`;
- задание: `materials/student/seminar_assignment.md`;
- пост-задание: `materials/student/post_assignment.md`;
- чек-лист: `materials/student/self_checklist.md`;
- спецификация DataLens: `datalens/dashboard_spec.md`.

## Как понять, что работа завершена

Проверьте, что:

- raw gate возвращает `STOP`, а clean gate — `CONTINUE`;
- после очистки осталось 23 922 обращения;
- временной ряд содержит 546 последовательных дней;
- прогноз сравнивается с baseline на одном test-периоде;
- порог выбран на validation, а не на test;
- для слабых сегментов предложен следующий проверочный шаг;
- `bi_export.csv` содержит 23 922 строки;
- итоговый вывод содержит факт, интерпретацию, риск, рекомендацию и ограничение.
