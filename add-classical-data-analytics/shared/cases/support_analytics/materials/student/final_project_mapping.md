# Как перенести кейс в итоговую работу

| Раздел итоговой работы | Артефакт семинара |
|---|---|
| Постановка задачи | Введение из `seminar_assignment.md` |
| Источники и модель данных | `docs/data_dictionary.md` и схема ключей |
| Качество данных | `data_validation_gate.csv`, `data_quality_report.csv` |
| Очистка и интеграция | Notebook `01` |
| Первичная визуализация | Графики из `outputs/charts/` |
| Временные ряды | Notebooks `02` и `02b` |
| Сегментация объектов | Notebook `03` |
| Прогнозный классификатор | Notebooks `04` и `04b` |
| Устойчивость модели | Notebook `04c` |
| Интерпретация | Notebook `05` и `executive_summary.md` |
| BI-представление | Папка `datalens/` и `bi_export.csv` |
| Ограничения и риски | Раздел ограничений в записке |
| Воспроизводимость | README, requirements и относительные пути |
