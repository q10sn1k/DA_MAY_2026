# Серия промптов для полного анализа датасета с ИИ: от поиска данных до итогового вывода

Этот файл содержит пошаговую серию промптов, которые можно копировать в ИИ-ассистента один за другим. Логика специально построена так, чтобы ассистент не выдавал весь анализ сразу, а работал поэтапно: сначала помогает найти датасет, затем описать данные, затем проверить качество, подготовить код, построить визуализации, сформулировать выводы и провести финальную проверку.

Серия рассчитана на ассистента, который работает как аналитический помощник для начинающего системного аналитика или junior data analyst. Основные правила: не выдумывать столбцы и значения, адаптировать анализ под реальные данные, использовать простой Python, pandas для табличной обработки и matplotlib для визуализаций; numpy, scikit-learn и другие более сложные библиотеки подключать только при реальной необходимости; отделять факт из данных от интерпретации и гипотезы.

---

## Как пользоваться серией промптов

1. Открой ИИ-ассистента с подключённым аналитическим preprompt.
2. Копируй промпты по одному, строго по порядку.
3. После каждого шага проверяй ответ ИИ.
4. Если ИИ предлагает перейти дальше, переходи только тогда, когда текущий шаг понятен.
5. Если ИИ начал делать сразу несколько этапов, останови его и верни к текущему шагу.
6. После загрузки CSV обязательно попроси ИИ работать только с реальными столбцами датасета.
7. Все выводы должны опираться на расчёты, а не на догадки.

Главное правило: один промпт — один аналитический шаг.

Правило по библиотекам: pandas и matplotlib являются базовыми инструментами пайплайна. numpy, scikit-learn, seaborn, scipy и другие дополнительные библиотеки подключаются только тогда, когда без них нельзя корректно решить текущую задачу.

---

## Универсальная команда-ограничитель для каждого шага

Этот текст можно добавлять в конец любого промпта, если ИИ начинает слишком сильно разгоняться и выдавать всё подряд.

```text
Работай только с текущим шагом. Не переходи к следующим этапам анализа, пока я не напишу «продолжай». Не делай финальные выводы заранее. Не придумывай столбцы, значения и бизнес-контекст. Если данных пока недостаточно, зафиксируй, чего не хватает, и остановись.
```

# Антиошибки: что писать ИИ, если он делает неправильно

## Если ИИ начал анализировать без данных

```text
Остановись. У тебя ещё нет реальных столбцов и значений датасета. Не делай выводы и не предлагай расчёты, пока не будет загружен CSV и не будет выполнен первичный осмотр данных.
```

## Если ИИ выдумал столбцы

```text
Остановись и перепроверь названия столбцов. Используй только реальные столбцы из загруженного CSV. Не придумывай поля, которых нет в датасете.
```

## Если ИИ сразу написал весь notebook

```text
Остановись. Мне нужен пошаговый режим. Сейчас выполни только текущий этап и в конце спроси: «Готов перейти к следующему шагу?».
```

## Если ИИ сделал слишком сложный код

```text
Упрости код для уровня начинающего аналитика. Используй pandas для таблиц и matplotlib для графиков. Не используй сложные функции, классы, ML-модели, numpy, scikit-learn и дополнительные библиотеки без явной необходимости.
```

## Если ИИ сделал слишком сильный вывод

```text
Перепиши вывод осторожнее. Раздели его на факт из данных, интерпретацию и гипотезу. Не делай причинно-следственный вывод, если он не подтверждён дизайном данных.
```

## Если ИИ не указал ограничения

```text
Добавь ограничения анализа. Укажи, какие выводы нельзя делать из этого датасета, каких данных не хватает и какие результаты требуют дополнительной проверки.
```

# Финальная формула работы с ИИ

Полный анализ с ИИ должен идти не как один большой ответ, а как последовательность управляемых шагов:

```text
найти данные → выбрать датасет → загрузить CSV → описать поля → поставить цель → проверить качество → очистить данные → выполнить EDA → построить графики → интерпретировать → указать ограничения → проверить notebook → сохранить результат
```

Если каждый шаг завершён и проверен, итоговый анализ получается воспроизводимым, понятным и защищённым от типовых ошибок: выдуманных столбцов, неподтверждённых выводов, случайной очистки данных и графиков без аналитического смысла.
