## Типовые причины снижения оценки

- выводы не связаны с расчётами;
- графики построены без интерпретации;
- нет проверки качества данных;
- BI построен на грязном исходном файле;
- корреляция описана как доказанная причина;
- ABC-XYZ/RFM выполнены без объяснения порогов;
- не приложены выходные файлы;
- notebook не запускается сверху вниз.
