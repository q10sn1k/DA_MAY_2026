## ABC-анализ

ABC-анализ делит объекты по вкладу в денежный показатель, например выручку.

Учебные пороги:

| Класс | Логика |
|---|---|
| A | объекты с накопленным вкладом до 80% |
| B | следующий слой до 95% |
| C | оставшиеся объекты |

Результат:

```text
outputs/abc_analysis.csv
```

## XYZ-анализ

XYZ-анализ оценивает стабильность спроса во времени через коэффициент вариации:

```text
CV = стандартное отклонение спроса / средний спрос
```

Учебные пороги:

| Класс | Логика |
|---|---|
| X | стабильный спрос |
| Y | умеренно изменчивый спрос |
| Z | нестабильный спрос |

Результат:

```text
outputs/xyz_analysis.csv
```

## ABC-XYZ-матрица

Матрица объединяет вклад и стабильность.

Примеры интерпретации:

| Класс | Интерпретация |
|---|---|
| AX | высокий вклад и стабильный спрос |
| AY | высокий вклад и умеренная изменчивость |
| AZ | высокий вклад, но нестабильный спрос |
| CZ | низкий вклад и нестабильный спрос |

Результат:

```text
outputs/abc_xyz_matrix.csv
```

## RFM-анализ

RFM-анализ сегментирует клиентов:

| Компонент | Значение |
|---|---|
| Recency | как давно клиент покупал |
| Frequency | как часто клиент покупает |
| Monetary | сколько денег принёс клиент |

Результаты:

```text
outputs/rfm_analysis.csv
outputs/rfm_segment_summary.csv
```

## Обогащённый BI-датасет
