# FAQ по типовым ошибкам при запуске проекта

## 1. Я открыл notebook, но файлы не находятся

### Возможная причина

Notebook открыт не из корня проекта или архив не распакован.

### Как проверить

Выполните:

```python
from pathlib import Path
Path.cwd()
```

Проверьте, что текущая папка — это папка проекта, где есть `data`, `notebooks`, `materials`, `outputs`.

### Как исправить

1. Распакуйте архив.
2. Откройте Jupyter из корня проекта.
3. Повторите проверку файлов.

---

## 2. Ошибка `FileNotFoundError`

### Возможная причина

Файл лежит не в той папке или путь указан неверно.

### Как проверить

```python
from pathlib import Path

Path("data/raw/orders_big.csv").exists()
```

### Как исправить

Проверьте, что файл лежит здесь:

```text
data/raw/orders_big.csv
```

---

## 3. Ошибка `ModuleNotFoundError: No module named 'pandas'`

### Возможная причина

В текущем Python-окружении не установлена библиотека pandas.

### Как исправить локально

```bash
pip install -r requirements.txt
```

### Резерв

Перейдите в Google Colab и загрузите notebook туда.

---

## 4. CSV открылся неправильно

### Возможная причина

У файла другой разделитель или кодировка.

### Что попробовать

```python
pd.read_csv("data/raw/my_file.csv", sep=";")
```

или:

```python
pd.read_csv("data/raw/my_file.csv", encoding="utf-8")
```

Если кириллица отображается некорректно:

```python
pd.read_csv("data/raw/my_file.csv", encoding="cp1251")
```

---

## 5. Дата прочиталась как текст

### Как проверить

```python
df.dtypes
```

### Как исправить

```python
df["date_column"] = pd.to_datetime(df["date_column"], errors="coerce")
```

После этого проверьте пропуски:

```python
df["date_column"].isna().sum()
```

---

## 6. После merge стало больше строк

### Возможная причина

Ключ в справочнике не уникален, поэтому строки размножились.

### Как проверить

```python
reference_table["key_column"].duplicated().sum()
```

### Как исправить

Проверить уникальность ключа и удалить или агрегировать дубликаты в справочнике.

---

## 7. После merge появились пропуски

### Возможная причина

В основной таблице есть ключи, которых нет в справочнике.

### Как проверить

```python
merged_df["field_from_reference"].isna().sum()
```

### Как исправить

Проверить ключи соединения, типы данных и наличие значений в справочнике.

---

## 8. Не создаётся `bi_dataset.csv`

### Возможная причина

Не выполнены предыдущие ячейки или папка `outputs` не создана.

### Как исправить

Выполните:

```python
from pathlib import Path
Path("outputs").mkdir(exist_ok=True)
```

Затем повторно выполните блок подготовки BI-датасета.

---

## 9. Второй notebook не запускается

### Возможная причина

Не создан файл:

```text
outputs/bi_dataset.csv
```

### Как исправить

Сначала выполните первый notebook до конца. Затем откройте второй notebook:

```text
notebooks/02_abc_xyz_rfm_student.ipynb
```

---

## 10. В RFM нет клиентов

### Возможная причина

В датасете нет идентификатора клиента.

### Что делать

Если нет поля вроде `client_id`, `customer_id` или `user_id`, RFM-анализ можно не выполнять. В итоговой работе нужно явно написать:

```text
RFM-анализ не выполнялся, потому что в выбранном датасете отсутствует идентификатор клиента.
```

---

## 11. График строится слишком долго

### Возможная причина

Вы строите scatter plot по всей большой таблице.

### Как исправить

Используйте выборку:

```python
sample_df = df.sample(min(3000, len(df)), random_state=42)
```

---

## 12. Корреляция получилась, но непонятно, что писать в выводе

### Правильная формулировка

```text
Между показателями наблюдается статистическая связь, однако она не доказывает причинно-следственную зависимость. Для более точного вывода требуется дополнительная проверка.
```

### Неправильная формулировка

```text
Показатель X влияет на показатель Y, потому что корреляция высокая.
```

## 13. Colab не видит файлы после перезапуска

### Возможная причина

Файлы были загружены во временную среду выполнения, которая сбросилась.

### Как исправить

Загрузите файлы заново или подключите Google Drive.

---

## 14. Notebook запускается не сверху вниз

### Почему это проблема

Если ячейки выполняются в случайном порядке, переменные могут быть не созданы или содержать старые значения.

### Как правильно

Выполняйте:

```text
Kernel / Runtime → Restart and Run All
```

или запускайте ячейки строго сверху вниз.
