# Гайд по выбору датасета для итоговой работы

## Главный принцип

Датасет должен позволять показать полный аналитический цикл:

```text
загрузка → очистка → EDA → статистика → взаимосвязи → BI → сегментация → выводы
```

## Хороший датасет

Подходит, если в нём есть:

| Признак | Зачем нужен |
|---|---|
| От 500 строк | чтобы группировки и статистика имели смысл |
| Несколько числовых полей | для статистики и корреляций |
| Несколько категориальных полей | для группировок и BI-фильтров |
| Дата или период | для динамики, XYZ и RFM |
| Идентификатор клиента или объекта | для RFM или сегментации |
| Денежный показатель | для ABC и BI-KPI |

## Датасет подходит хорошо, если можно ответить на вопросы

- Какие группы дают основной вклад?
- Как показатели меняются во времени?
- Какие признаки связаны между собой?
- Какие сегменты можно выделить?
- Какие выводы можно передать руководителю?

## Датасет подходит плохо, если

- в нём меньше 100 строк;
- есть только текст без числовых показателей;
- нет категорий;
- нет понятной аналитической задачи;
- нельзя построить BI-дашборд;
- нет возможности сделать выводы;
- данные содержат персональную или закрытую информацию.

## Что нужно для RFM

Для RFM нужны:

| Поле | Пример |
|---|---|
| клиент | `client_id`, `customer_id`, `user_id` |
| дата покупки | `order_date`, `purchase_date` |
| заказ или транзакция | `order_id`, `transaction_id` |
| сумма покупки | `revenue`, `amount`, `sales` |

Если этих полей нет, RFM можно не выполнять, но нужно явно объяснить причину.

## Что нужно для ABC-XYZ

Для ABC нужны:

- объект анализа: товар, категория, клиент, регион;
- показатель вклада: выручка, продажи, сумма.

Для XYZ нужны:

- объект анализа;
- период;
- показатель спроса по периодам.

## Безопасность данных

Не используйте:

- персональные данные реальных людей;
- телефоны, email, адреса;
- закрытые рабочие выгрузки;
- токены, пароли, ключи;
- медицинские, финансовые или иные чувствительные сведения без разрешения.

Если используете публичный датасет, укажите ссылку на источник.
