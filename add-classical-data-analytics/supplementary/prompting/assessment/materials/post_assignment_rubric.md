# Рубрика оценивания самостоятельной работы

Максимальная оценка — 100 баллов.

| Блок | Критерий | Баллы |
|---|---|---:|
| Постановка задачи | Выявлены неоднозначности исходного запроса | 5 |
| Постановка задачи | Сформулированы измеримые аналитические вопросы | 10 |
| Первый промт | Указаны цель, контекст и доступные данные | 10 |
| Первый промт | Заданы действия, формат и критерии готовности | 10 |
| Рецензирование | Найдены конкретные недостатки первого ответа | 10 |
| Итерация | Корректирующий промт адресует найденные недостатки | 10 |
| Качество данных | Выполнены проверки типов, пропусков, дубликатов и диапазонов | 10 |
| Расчёты | KPI и срезы рассчитаны корректно | 15 |
| Проверка LLM | Не менее двух утверждений модели сверены с данными | 5 |
| Интерпретация | Факты, гипотезы и ограничения разделены | 10 |
| Безопасность | Описаны минимизация данных и недоверенный внешний контент | 5 |
| **Итого** |  | **100** |

## Уровни выполнения

- **90–100 баллов:** работа готова, логика воспроизводима, выводы аккуратны;
- **75–89 баллов:** хороший результат с отдельными недочётами;
- **60–74 балла:** базовая задача выполнена, но проверка или интерпретация неполны;
- **40–59 баллов:** существенные пробелы в постановке, расчётах или проверке;
- **0–39 баллов:** работа не демонстрирует полный цикл промтинга.

## Критические ошибки

При наличии любой из ошибок итоговая оценка не может превышать 59 баллов:

- использованы реальные чувствительные данные без разрешённого процесса;
- notebook не запускается сверху вниз;
- вывод содержит числа, которых нет в расчётах;
- несуществующие поля используются как фактические;
- причинность объявлена доказанной только по агрегированной связи;
- отсутствует собственная проверка ответа модели.
