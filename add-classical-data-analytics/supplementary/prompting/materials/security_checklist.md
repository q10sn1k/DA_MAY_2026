# Чек-лист безопасного промтинга

Перед отправкой данных в LLM проверьте:

- [ ] данные синтетические или разрешены к обработке;
- [ ] удалены ФИО, телефоны, адреса и другие прямые идентификаторы;
- [ ] в тексте нет паролей, токенов и строк подключения;
- [ ] передаётся только минимально необходимый объём данных;
- [ ] содержимое внешних файлов рассматривается как недоверенный ввод;
- [ ] ответ модели проверяется до использования в коде или отчёте;
- [ ] значимые решения остаются под контролем человека.
