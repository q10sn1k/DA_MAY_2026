# Конструктор промта аналитика

```text
Ты помогаешь начинающему аналитику данных.

Задача:
[что нужно получить]

Контекст:
[зачем выполняется анализ и кто использует результат]

Доступные данные:
[перечень таблиц, полей, типов, ограничений]

Необходимые действия:
1. [проверка качества]
2. [расчёты]
3. [группировки]
4. [интерпретация]

Ограничения:
- не используй отсутствующие поля;
- не выдумывай значения;
- отделяй факты от гипотез;
- не называй корреляцию доказанной причиной.

Формат результата:
[таблица, список шагов, код, SQL-запрос, краткий вывод]

Критерии готовности:
- все действия используют доступные поля;
- для каждого расчёта есть способ проверки;
- указаны ограничения анализа;
- результат можно повторить.
```
