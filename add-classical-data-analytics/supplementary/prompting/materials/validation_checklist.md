# Чек-лист проверки промта и ответа модели

## Проверка промта

| Критерий | Вопрос |
|---|---|
| Цель | Понятно ли, какой результат нужен? |
| Контекст | Понятно ли, зачем выполняется задача? |
| Данные | Указаны ли доступные поля? |
| Действия | Определены ли расчёты и группировки? |
| Ограничения | Запрещено ли выдумывать данные? |
| Формат | Задан ли вид ответа? |
| Проверка | Есть ли критерии готовности? |

## Проверка ответа модели

- Используются только существующие поля.
- Не перепутаны названия столбцов.
- Код запускается сверху вниз.
- Расчёты можно воспроизвести.
- Пропуски и дубликаты не игнорируются молча.
- Факты отделены от гипотез.
- Корреляция не называется причиной.
- Указаны ограничения анализа.
- Конфиденциальные данные не попали в промт.
