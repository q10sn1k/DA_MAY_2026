# Проверка гипотезы и прогноз нагрузки по обращениям

## Цель

Комплект помогает выполнить самостоятельную работу: проверить гипотезу о различии времени решения обращений между каналами `email` и `chat`, построить недельный временной ряд обращений, сделать базовый прогноз и оформить аналитический вывод.

## Состав комплекта

| Файл | Назначение |
|---|---|
| `data/raw/support_tickets.csv` | учебный синтетический датасет обращений в поддержку |
| `notebooks/hypothesis_timeseries_student_template.ipynb` | notebook-шаблон для выполнения задания |
| `materials/student_assignment_brief.md` | краткая формулировка задания |
| `materials/data_dictionary.md` | описание полей датасета |
| `scripts/generate_support_tickets.py` | скрипт для повторной генерации датасета |
| `requirements.txt` | список библиотек |
| `outputs/` | папка для сохранения результатов |

## Как запустить

1. Распакуйте архив.
2. Откройте папку `hypothesis_timeseries_student_package` как рабочую папку проекта.
3. Установите зависимости при необходимости:

```bash
pip install -r requirements.txt
```

4. Откройте файл `notebooks/hypothesis_timeseries_student_template.ipynb`.
5. Запускайте ячейки сверху вниз.
6. Сохраните итоговую таблицу прогноза в `outputs/forecast_comparison.csv`.

## Важно

В датасете есть контролируемые учебные проблемы качества: несколько некорректных дат, пропуски в `resolution_hours`, отрицательные значения, дубликаты `ticket_id`, разные регистры в `channel` и лишние пробелы в `category`. Эти проблемы добавлены специально, чтобы отработать проверку и очистку данных.

## Ожидаемый результат

К концу работы должны быть подготовлены:

- таблица первичной проверки качества данных;
- H0 и H1 по сравнению каналов `email` и `chat`;
- таблица описательного сравнения групп;
- результат t-test с p-value;
- недельный временной ряд обращений;
- график факта и скользящего среднего;
- baseline-прогноз на последние 4 недели;
- метрики MAE и RMSE;
- итоговый аналитический вывод с ограничениями.

## Чек-лист завершения

- Notebook запускается сверху вниз.
- Используются относительные пути.
- Дата преобразована через `pd.to_datetime()`.
- Проверены пропуски, дубликаты и некорректные значения.
- H0 и H1 записаны до интерпретации теста.
- p-value сравнивается с `alpha = 0.05`.
- Train/test split сделан по времени.
- Forecast сравнен с fact.
- Итоговый вывод не содержит категоричных формулировок без ограничений.
