# Описание данных `support_tickets.csv`

Датасет синтетический и предназначен только для учебных задач. Он не содержит персональных данных, паролей, токенов или рабочих доступов.

| Поле | Тип | Назначение | Пример |
|---|---|---|---|
| `ticket_id` | string | идентификатор обращения | `TCK-00001` |
| `created_at` | datetime/string | дата и время создания обращения | `2026-01-05 10:15:00` |
| `channel` | string | канал обращения | `email`, `chat`, `phone`, `web` |
| `priority` | string | приоритет обращения | `low`, `medium`, `high`, `critical` |
| `category` | string | категория обращения | `billing`, `technical`, `access` |
| `customer_segment` | string | сегмент клиента | `B2C`, `SMB`, `Enterprise` |
| `region` | string | макрорегион | `Central`, `Volga` |
| `resolution_hours` | float | время решения обращения в часах | `8.75` |
| `sla_missed` | integer | признак просрочки SLA: 1 — просрочено, 0 — не просрочено | `0` |
| `satisfaction_score` | integer | оценка клиента от 1 до 5 | `4` |
| `first_response_minutes` | integer | время первого ответа в минутах | `42` |

## Контролируемые проблемы качества

| Проблема | Где встречается | Учебная цель |
|---|---|---|
| Некорректные даты | `created_at` | отработать `pd.to_datetime(..., errors="coerce")` |
| Пропуски | `resolution_hours` | показать диагностику пропусков |
| Отрицательные значения | `resolution_hours` | проверить бизнес-правило: время решения не может быть отрицательным |
| Дубликаты | `ticket_id` | показать проверку дублей |
| Разный регистр | `channel` | нормализовать категории через `.str.lower()` |
| Лишние пробелы | `category` | нормализовать текст через `.str.strip()` |
