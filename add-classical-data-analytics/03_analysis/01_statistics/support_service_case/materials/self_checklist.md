# Самопроверка практической работы

- [ ] Notebook запускается сверху вниз без ошибок.
- [ ] Используются относительные пути.
- [ ] Все три CSV найдены.
- [ ] Дата `created_at` преобразована в datetime.
- [ ] Пропуски, дубли и категории проверены.
- [ ] Повторные `ticket_id` обработаны.
- [ ] После `merge` количество строк проверено.
- [ ] Корреляция рассчитана по числовым полям.
- [ ] Корреляция не интерпретируется как причинность.
- [ ] Для гипотез сформулированы H0 и H1.
- [ ] Для каждой гипотезы указаны размеры групп, средние и p-value.
- [ ] Временной ряд отсортирован по датам.
- [ ] Train находится раньше test.
- [ ] Сложный прогноз сравнивается с baseline.
- [ ] Таблицы и графики сохранены в `outputs`.
- [ ] Итоговый вывод содержит ограничения и следующий шаг.
