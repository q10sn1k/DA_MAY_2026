# Анализ обращений в службу поддержки

## Цель

Проверить качество данных, объединить таблицы, исследовать взаимосвязи, проверить статистические гипотезы и построить прогноз количества обращений.

## Основной файл

```text
notebooks/student_practice.ipynb
```

## Исходные данные

```text
data/raw/support_tickets.csv
data/raw/customers.csv
data/raw/regions.csv
```

## Порядок работы

1. Распакуйте архив целиком.
2. Установите зависимости из `requirements.txt`.
3. Запустите Jupyter Notebook.
4. Откройте `notebooks/student_practice.ipynb`.
5. Выполняйте ячейки сверху вниз.
6. После каждого крупного блока отвечайте на контрольные вопросы.
7. Сохраните итоговые таблицы и графики в `outputs`.
8. Заполните итоговый аналитический вывод.

## Что должно получиться

- очищенная объединённая таблица;
- показатели по каналам и категориям;
- корреляционная матрица;
- результаты минимум двух гипотез;
- дневной временной ряд;
- несколько baseline-прогнозов;
- сравнение прогнозов по MAE и RMSE;
- итоговый аналитический вывод с ограничениями.

## Что показать преподавателю

- выполненный notebook;
- результаты проверки качества;
- график связи времени решения и оценки;
- таблицу гипотез;
- временной ряд и прогноз;
- файлы из `outputs`;
- краткий вывод своими словами.
