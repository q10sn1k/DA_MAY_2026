# Анализ службы поддержки: Python и Yandex DataLens

## Что входит в комплект

Комплект позволяет пройти путь от очистки и статистического анализа в Python до интерактивного дашборда в Yandex DataLens.

## Начало работы

1. Распакуйте архив целиком.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Откройте `notebooks/student_practice.ipynb`.
4. Выполняйте ячейки сверху вниз.
5. Перейдите к блоку интеграции с DataLens.
6. Используйте `materials/datalens/student_datalens_guide.md`.

## DataLens

Готовые витрины находятся в `data/datalens/`. Для практики предусмотрены:

- операционный обзор;
- лаборатория гипотез;
- динамика и прогноз;
- селекторы и вычисляемые поля;
- QA-чек-лист.

Графики используются для исследования и объяснения. Статистические тесты рассчитываются в Python.

## Что показать

- выполненный notebook;
- сохранённые outputs;
- дашборд DataLens или его проект по blueprint;
- одну гипотезу с p-value и ограничением вывода.
