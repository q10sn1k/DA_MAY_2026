# Словарь данных

| Поле | Тип в R | Назначение | Пример |
|---|---|---|---|
| `order_id` | character | Уникальный идентификатор заказа | `ORD-100001` |
| `order_date` | Date после преобразования | Дата заказа | `2026-01-15` |
| `region` | character | Регион продажи | `Москва` |
| `channel` | character | Канал продаж | `online` |
| `category` | character | Категория товара | `Ноутбуки` |
| `product` | character | Наименование товара | `Ноутбук Pro 15` |
| `quantity` | numeric | Количество единиц | `2` |
| `unit_price` | numeric | Цена единицы | `73500` |
| `discount_pct` | numeric | Скидка долей единицы | `0.10` |
| `status` | character | Статус заказа | `completed` |

## Гранулярность

Одна строка представляет одну товарную позицию заказа. В учебном наборе один `order_id` соответствует одной строке, но в реальных данных заказ может включать несколько позиций. Это ограничение следует учитывать при интерпретации среднего чека.

## Контролируемые проблемы качества

- пустые значения региона;
- полные дубликаты;
- лишние пробелы в текстовых полях;
- различающийся регистр статуса;
- нулевое или отрицательное количество;
- нулевая цена;
- отменённые и возвращённые заказы.
