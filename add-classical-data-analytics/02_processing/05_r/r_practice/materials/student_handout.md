# Практическая работа: обработка данных в R

## Цель

Загрузить CSV с транзакциями, проверить его качество, очистить данные, рассчитать показатели, построить визуализации и сохранить результаты.

## Что получится

- объект `sales_clean` с подготовленными транзакциями;
- таблицы `region_summary`, `category_summary`, `monthly_summary`, `channel_summary`;
- графики выручки по регионам, месяцам и каналам;
- CSV-файлы в папке `outputs`;
- краткий аналитический вывод.

## Подготовка

1. Распакуйте комплект.
2. Откройте `r_data_basics.Rproj`.
3. Выполните `scripts/install_packages.R`.
4. Откройте `scripts/student_practice.R`.
5. Выполняйте команды сверху вниз.

## Логика работы

1. Подключить пакет.
2. Проверить среду и файл.
3. Загрузить CSV.
4. Проверить размер, типы, пропуски и дубликаты.
5. Нормализовать текстовые поля.
6. Удалить дубликаты и некорректные строки.
7. Рассчитать выручку.
8. Создать агрегированные таблицы.
9. Построить графики.
10. Экспортировать результат.
11. Сформулировать вывод.

## Контрольные значения

- исходная таблица: 726 строк и 10 столбцов;
- после очистки должно остаться 613 строк;
- итоговая выручка должна составить 25 143 394.52.

Число может отображаться в научной записи. Для проверки используйте:

```r
format(sum(sales_clean$revenue), scientific = FALSE)
```

## Самостоятельный мини-кейс

Рассчитайте показатели по каналам продаж:

- число уникальных заказов;
- число проданных единиц;
- выручку;
- средний чек.

Отсортируйте таблицу по убыванию выручки и постройте столбчатую диаграмму.

## Структура вывода

1. Какой регион является лидером по выручке?
2. Какая категория лидирует?
3. Как изменялась выручка по месяцам?
4. Какой канал является основным?
5. Какие строки были исключены и почему?
6. Какое ограничение есть у выполненного анализа?

## Что показать преподавателю

- скрипт выполняется сверху вниз;
- контрольные значения совпадают;
- четыре итоговые таблицы созданы;
- три графика построены;
- файлы сохранены в `outputs`;
- вывод содержит ссылки на конкретные показатели.
