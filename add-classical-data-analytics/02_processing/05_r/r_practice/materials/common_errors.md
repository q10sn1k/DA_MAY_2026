# Типовые ошибки и диагностика

| Сообщение или симптом | Вероятная причина | Что проверить | Исправление |
|---|---|---|---|
| `could not find function` | Пакет не подключён | Выполнен ли `library(tidyverse)` | Подключить пакет |
| `there is no package called` | Пакет не установлен | Результат `installed.packages()` | Выполнить `install_packages.R` |
| `cannot open file` | Проект открыт не из корня | `getwd()` и панель Files | Открыть `.Rproj` |
| CSV загрузился одним столбцом | Другой разделитель | Первые строки файла | Использовать `read_delim()` |
| `object not found` | Объект не создан | Порядок выполнения строк | Запустить код сверху вниз |
| `NA` в итоговой сумме | В данных остались пропуски | `sum(is.na(revenue))` | Обработать пропуски или добавить `na.rm = TRUE` осознанно |
| После фильтра нет строк | Ошибка условия или значений | `unique(status)` и `nrow()` | Нормализовать регистр и пробелы |
| Итоговая сумма завышена | Дубликаты не удалены | `sum(duplicated(sales_raw))` | Выполнить `distinct()` |
| График пустой | Агрегированная таблица пустая | Вывести таблицу до `ggplot()` | Исправить предыдущий шаг |
| Категории отсортированы неверно | Порядок не задан | Таблица до графика | Использовать `reorder()` и `arrange()` |
