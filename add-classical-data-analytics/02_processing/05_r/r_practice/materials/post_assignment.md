# Самостоятельная работа: расширение анализа продаж

## Цель

Закрепить загрузку, преобразование, группировку, визуализацию и экспорт данных в R на основе знакомого набора транзакций.

## Задание

1. Создайте таблицу `product_summary` по товарам.
2. Рассчитайте число заказов, количество единиц, выручку и среднюю цену продажи.
3. Выберите пять товаров с максимальной выручкой.
4. Постройте горизонтальную столбчатую диаграмму топ-5 товаров.
5. Рассчитайте долю каждого товара в общей выручке.
6. Сохраните таблицу в `outputs/top_products.csv`.
7. Сохраните график в `outputs/top_products.png`.
8. Напишите вывод из 5–7 предложений.

## Требования к выводу

- назовите лидирующий товар;
- укажите его выручку и долю;
- сравните первое и пятое место;
- опишите минимум одно ограничение;
- предложите следующий аналитический шаг.

## Формат сдачи

- заполненный `.R`-скрипт;
- `top_products.csv`;
- `top_products.png`;
- текстовый вывод.

## Критерии

| Критерий | Баллы |
|---|---:|
| Корректная группировка и расчёты | 4 |
| Правильный топ-5 и сортировка | 2 |
| Читаемая визуализация | 2 |
| Вывод основан на показателях | 2 |
| **Итого** | **10** |
