# Диагностика ошибок R и RStudio

| Сообщение или симптом | Вероятная причина | Решение |
|---|---|---|
| RStudio открылся, но код не выполняется | R не установлен или установлен после RStudio с ошибкой | установить R с CRAN, затем перезапустить RStudio |
| `there is no package called ...` | пакет не установлен | выполнить `install.packages("имя_пакета")` |
| `could not find function ...` | пакет установлен, но не подключён | выполнить `library(имя_пакета)` |
| `cannot open file` | неверная рабочая папка | открыть `.Rproj`, проверить `getwd()` |
| `products.xlsx` не читается | не установлен `readxl` или неверный лист | установить `readxl`, проверить `sheet = "products"` |
| `regions.json` не читается | не установлен `jsonlite` | установить `jsonlite` |
| в outputs нет файлов | скрипт не выполнен до конца или нет папки | выполнить скрипт сверху вниз, проверить сообщения в консоли |
| результаты отличаются от преподавателя | другая версия файлов или пропущен шаг | заново распаковать архив и выполнить скрипт сверху вниз |


## Дополнение: ошибки при подготовке витрины в R

| Ошибка | Вероятная причина | Как исправить |
|---|---|---|
| `could not find function "relationship"` или ошибка в `left_join` | Установлена старая версия dplyr | Убрать параметр `relationship` или обновить tidyverse |
| Итоговая витрина содержит больше 150 строк | Справочники не были очищены от дублей | Проверить `distinct(product_id, .keep_all = TRUE)` и аналогичные шаги |
| `revenue_zscore` отличается от Python | Использована выборочная стандартная ошибка `sd()` | Использовать population std: `sqrt(mean((x - mean(x))^2))` |
| Даты стали `NA` | В данных есть невалидные даты | Это ожидаемо для строк с ошибками качества |
| Сводка по регионам содержит меньше строк | Часть строк была исключена или не присоединился справочник | Проверить флаги и `left_join` |
