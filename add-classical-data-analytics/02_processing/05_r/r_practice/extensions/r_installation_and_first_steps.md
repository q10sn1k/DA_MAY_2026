# Установка R, запуск RStudio и первые операции с данными

## Назначение комплекта

Этот комплект предназначен для третьего 90-минутного блока. Его задача — не изучать R абстрактно, а перенести знакомый кейс входного аудита данных в новую среду.

Слушатель уже видел эти данные в Python. Теперь он должен:

- установить или проверить R;
- открыть RStudio;
- открыть проектную папку;
- проверить рабочую директорию;
- установить и подключить пакеты;
- загрузить CSV, XLSX и JSON;
- выполнить первые проверки качества данных в R;
- сохранить первые результаты в `outputs`.

## Что установить

1. R с официального сайта R Project / CRAN.
2. RStudio Desktop с сайта Posit.
3. Пакеты R: `tidyverse`, `readxl`, `jsonlite`.

## Почему R и RStudio устанавливаются отдельно

R — это язык и вычислительная среда. RStudio — это среда разработки, которая помогает писать, запускать и отлаживать код, смотреть таблицы, графики и рабочую область.

## Быстрая проверка после установки

Откройте RStudio и выполните в консоли:

```r
R.version.string
getwd()
```

Если команды выполняются без ошибки, R запущен.

## Установка пакетов

В RStudio откройте файл:

```text
r/03_setup_packages.R
```

Запустите его целиком. Он установит недостающие пакеты и подключит их.

Ручной вариант:

```r
install.packages("tidyverse")
install.packages("readxl")
install.packages("jsonlite")

library(tidyverse)
library(readxl)
library(jsonlite)
```

## Правильный запуск проекта

Рекомендуемый вариант:

1. Распакуйте архив.
2. Откройте файл `data_quality_audit_case_v1.Rproj`.
3. В RStudio откройте файл `r/03_r_check_environment.R`.
4. Запустите скрипт.
5. Убедитесь, что все файлы в таблице проверки имеют значение `TRUE`.

## Частые ошибки

| Ошибка | Возможная причина | Что сделать |
|---|---|---|
| `could not find function read_csv` | не подключён `tidyverse` | выполнить `library(tidyverse)` |
| `there is no package called readxl` | пакет не установлен | выполнить `install.packages("readxl")` |
| файл не найден | RStudio открыт не из корня проекта | открыть `.Rproj` или проверить `getwd()` |
| JSON не читается | не установлен `jsonlite` | выполнить `install.packages("jsonlite")` |
| кириллица в CSV отображается странно | проблема кодировки или локали | использовать подготовленные файлы и проверить системную локаль |

## Методический смысл

Главное в этом блоке — показать, что R используется для той же аналитической задачи, что и Python: загрузить данные, проверить структуру, найти проблемы качества и сохранить результат. Слушатель переносит уже понятную рабочую логику в новый инструмент.
