# Python, очистка данных и SQL в сквозном аналитическом кейсе

Этот комплект содержит учебные данные и SQL-файлы для интеграционного практического вебинара.

## Состав

```text
project/
├── data/
│   ├── raw/
│   │   ├── sales.csv
│   │   ├── products.xlsx
│   │   ├── regions.json
│   │   └── clients.csv
│   └── processed/
├── notebooks/
│   └── notebooks_will_be_added_later.txt
├── sql/
│   ├── analytics_demo.sqlite
│   ├── create_database.sql
│   └── practice_queries.sql
├── outputs/
├── docs/
│   ├── data_dictionary.md
│   └── qa_checklist.md
└── requirements.txt
```

## Как использовать

1. Распакуйте архив.
2. Откройте папку проекта как рабочую папку.
3. Убедитесь, что файлы данных находятся в `data/raw`.
4. Notebook-файлы будут добавлены следующим этапом.
5. Результаты практики сохраняйте в папку `outputs`.

## Учебная задача

Нужно пройти рабочий цикл аналитика:

```text
загрузка данных -> проверка качества -> очистка -> расчёты pandas -> SQL-сверка -> аналитический вывод
```

## Заложенные учебные ошибки

В данных специально есть контролируемые проблемы:

- пропуски в `region_id` и `client_id`;
- дубликаты `order_id`;
- даты в разных форматах и некорректные даты;
- разный регистр и лишние пробелы в текстовых полях;
- отрицательное количество, нулевая цена, скидка больше 1;
- несуществующие ключи `product_id` и `region_id`;
- дубль `product_id` в справочнике товаров.

Эти ошибки нужны для учебной диагностики и очистки данных.

## Дополнительная практика на 90 минут

В комплект добавлен расширяющий модуль **«От очищенных данных к аналитическому мини-отчёту»**. Он нужен, если основной кейс группа прошла быстрее ожидаемого времени.

Файлы модуля:

| Файл | Назначение |
|---|---|
| `notebooks/extra_practice_analytics_report.ipynb` | notebook для слушателей |
| `notebooks/extra_practice_teacher_solution.ipynb` | эталонное решение для преподавателя |
| `docs/extra_practice_student_handout.md` | чистая инструкция для слушателей |
| `docs/extra_practice_teacher_notes.md` | методические заметки преподавателя |
| `docs/extra_practice_reference_results.md` | контрольные значения |
| `sql/extra_practice_queries_template.sql` | SQL-шаблоны для слушателей |
| `sql/extra_practice_queries_solution.sql` | SQL-решение для преподавателя |

Результат модуля: KPI-таблица, аналитические срезы, 3 графика, SQL-сверка и короткий управленческий вывод.


## Русские подписи и словарь терминов

В материалах добавлены дополнительные русские пояснения. Технические имена столбцов в коде остаются на английском, чтобы Python, pandas и SQL-запросы работали без ошибок, но в пояснениях и итоговых выводах используются русские названия.

Полезный файл: `docs/russian_terms_glossary.md`.

В notebook добавлена функция `display_ru()`. Она показывает итоговые таблицы с русскими подписями столбцов, не меняя исходные данные и не ломая код.
