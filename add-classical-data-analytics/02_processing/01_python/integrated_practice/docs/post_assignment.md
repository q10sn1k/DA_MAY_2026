# Пост-задание: самостоятельная аналитическая проверка продаж

## Цель

Закрепить полный базовый цикл работы аналитика с данными: загрузить несколько файлов, проверить качество данных, очистить таблицы, рассчитать показатели в pandas, выполнить SQL-сверку и оформить краткий аналитический вывод.

## Исходная ситуация

Вы получили набор файлов с данными о продажах компании. В данных есть типовые проблемы качества: дубликаты заказов, пропуски, некорректные даты, разные написания текстовых значений и строки, которые не проходят базовые бизнес-правила.

Ваша задача — подготовить данные к анализу, рассчитать ключевые показатели и объяснить, какие выводы можно сделать по результатам.

## Инструменты

- Jupyter Notebook или Google Colab;
- Python;
- pandas;
- SQLite;
- исходные файлы из папки `data/raw`;
- база `sql/analytics_demo.sqlite`.

## Исходные данные

Используйте файлы:

| Файл | Назначение |
|---|---|
| `data/raw/sales.csv` | заказы и продажи |
| `data/raw/products.xlsx` | справочник товаров |
| `data/raw/regions.json` | справочник регионов |
| `data/raw/clients.csv` | справочник клиентов |
| `sql/analytics_demo.sqlite` | учебная база для SQL-запросов |

## Что нужно сделать

### Часть 1. Подготовка проекта

1. Откройте папку проекта.
2. Откройте `notebooks/post_assignment_template.ipynb`.
3. Запустите notebook сверху вниз.
4. Проверьте, что все исходные файлы найдены.

### Часть 2. Загрузка данных

1. Загрузите `sales.csv` в DataFrame `sales`.
2. Загрузите `products.xlsx` в DataFrame `products`.
3. Загрузите `regions.json` в DataFrame `regions`.
4. Загрузите `clients.csv` в DataFrame `clients`.
5. Выведите первые строки и размеры всех таблиц.

### Часть 3. Проверка качества данных

Проверьте в таблице `sales`:

1. количество строк и столбцов;
2. типы данных;
3. пропуски;
4. дубликаты по `order_id`;
5. некорректные значения `quantity`, `unit_price`, `discount`;
6. значения в столбце `channel`.

Зафиксируйте найденные проблемы в отдельном markdown-блоке notebook.

### Часть 4. Очистка данных

Выполните очистку:

1. преобразуйте `order_date` в дату;
2. приведите `channel` к единому виду;
3. приведите `category` в `products` к единому виду;
4. удалите дубликаты заказов по `order_id`;
5. исключите строки с некорректными значениями `quantity`, `unit_price`, `discount`;
6. создайте столбец `revenue`.

### Часть 5. Объединение таблиц

1. Объедините продажи с товарами по `product_id`.
2. Объедините результат с регионами по `region_id`.
3. Объедините результат с клиентами по `client_id`.
4. Проверьте, не изменилось ли неожиданно количество строк.
5. Проверьте строки, где не найден товар, регион или клиент.

### Часть 6. Расчёты в pandas

Рассчитайте:

1. выручку по регионам;
2. выручку по категориям;
3. выручку по каналам продаж;
4. выручку по месяцам;
5. выручку по клиентским сегментам;
6. сводную таблицу `category × channel`.

Сохраните результаты в папку `outputs`.

### Часть 7. SQL-сверка

Выполните SQL-запросы к базе `analytics_demo.sqlite`:

1. выведите первые 5 строк таблицы `sales`;
2. посчитайте выручку по `region_id`;
3. сделайте `JOIN` с таблицами `products` и `regions`;
4. сравните результат SQL с результатом pandas;
5. объясните возможные причины расхождений.

### Часть 8. Аналитический вывод

В конце notebook напишите вывод по структуре:

```text
1. Что анализировалось:
2. Какие проблемы качества были найдены:
3. Какие показатели рассчитаны:
4. Какие регионы, категории или каналы оказались лидерами:
5. Совпали ли результаты pandas и SQL:
6. Какие ограничения анализа нужно учитывать:
7. Что можно рекомендовать как следующий шаг:
```

## Типовые ошибки

| Ошибка | Как исправить |
|---|---|
| Файл не найден | проверить текущую папку и структуру проекта |
| CSV открылся одной колонкой | проверить разделитель и параметр `sep` |
| Дата не преобразовалась | использовать `pd.to_datetime(..., errors="coerce")` |
| После `merge` появились пропуски | проверить ключи соединения и справочники |
| Суммы pandas и SQL не совпали | сравнить фильтры, дубликаты и правила очистки |
| Не сохранились outputs | проверить папку `outputs` и права на запись |
