# Дополнительная практика: от очищенных данных к аналитическому мини-отчёту

## Назначение

Эта практика рассчитана примерно на 90 минут и продолжает основной кейс по Python, очистке данных и SQL. В основной части данные были загружены, проверены, очищены и сверены через SQL. В дополнительном блоке нужно довести работу до мини-отчёта: собрать KPI, построить несколько аналитических таблиц и графиков, выполнить SQL-сверку и сформулировать вывод.

## Что получится в результате

К концу практики у вас должны быть:

| Результат | Где будет находиться |
|---|---|
| KPI-таблица | в notebook и `outputs/extra_kpi_summary.csv` |
| Динамика выручки по месяцам | в notebook и `outputs/extra_monthly_revenue.csv` |
| Топ-5 регионов | в notebook и `outputs/extra_top_regions.csv` |
| Таблица по категориям | в notebook и `outputs/extra_top_categories.csv` |
| Сводная матрица категория × канал | `outputs/extra_category_channel_matrix.xlsx` |
| Мини-отчёт | `outputs/analytics_report_template.md` или markdown-блок в notebook |

## Ход работы

### Шаг 1. Откройте notebook

Откройте файл:

```text
notebooks/extra_practice_analytics_report.ipynb
```

Выполняйте ячейки сверху вниз.

### Шаг 2. Проверьте файлы

Убедитесь, что notebook видит исходные данные. Если файл не найден, проверьте, что вы открыли проект из корневой папки.

### Шаг 3. Повторите базовую подготовку данных

Выполните блоки загрузки, очистки и объединения таблиц. В результате должна появиться таблица `sales_full`.

### Шаг 4. Соберите KPI

Рассчитайте:

| Показатель | Формула или логика |
|---|---|
| Общая выручка | сумма `revenue` |
| Количество заказов | `nunique()` по `order_id` |
| Средняя выручка на заказ | среднее значение `revenue` |
| Средняя скидка | среднее значение `discount` |
| Доля заказов со скидкой | среднее значение признака `discount > 0` |

### Шаг 5. Постройте аналитические таблицы

Подготовьте:

1. Выручку по месяцам.
2. Топ-5 регионов по выручке.
3. Выручку по категориям.
4. Сводную таблицу категория × канал.
5. Выручку по группам скидок.

### Шаг 6. Постройте графики

Минимальный набор:

| График | Что показывает |
|---|---|
| Динамика выручки по месяцам | как менялась выручка во времени |
| Топ-5 регионов | какие регионы дают больше всего выручки |
| Выручка по категориям | какие категории лидируют |

### Шаг 7. Выполните SQL-сверку

Откройте файл:

```text
sql/extra_practice_queries_template.sql
```

Выполните запросы по группам скидок, регионам, категориям и каналам. Сравните смысл результата с pandas-таблицами.

### Шаг 8. Сформулируйте мини-отчёт

Используйте структуру:

```text
1. Что анализировалось.
2. Какие данные были подготовлены.
3. Какие показатели рассчитаны.
4. Что видно по регионам, категориям, каналам или скидкам.
5. Какие ограничения качества данных нужно учитывать.
6. Какой следующий шаг стоит сделать.
```
