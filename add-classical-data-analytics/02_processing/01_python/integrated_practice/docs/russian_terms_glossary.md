# Русские подписи и словарь терминов

Этот файл помогает читать notebook и SQL-запросы на русском языке. В коде часть названий остаётся на английском, потому что это технические имена столбцов и переменных. Их лучше не менять внутри исходных данных: так notebook, SQL-запросы и файлы CSV/XLSX/JSON остаются совместимыми между собой.

## Главное правило

- В коде используем технические имена: `order_id`, `revenue`, `region_name`, `groupby`, `merge`.
- В пояснениях, выводах, подписях таблиц и графиков используем русские названия: «номер заказа», «выручка», «регион», «группировка», «объединение таблиц».

## Перевод полей данных

| Техническое имя | Русское название | Простое объяснение |
|---|---|---|
| `order_id` | Номер заказа | Уникальный идентификатор заказа |
| `order_date` | Дата заказа | Когда был оформлен заказ |
| `client_id` | Код клиента | Идентификатор клиента |
| `product_id` | Код товара | Идентификатор товара |
| `region_id` | Код региона | Идентификатор региона |
| `channel` | Канал продаж | Где прошла продажа: сайт, офлайн, партнёр, приложение |
| `quantity` | Количество | Сколько единиц товара купили |
| `unit_price` | Цена за единицу | Цена одной единицы товара |
| `discount` | Скидка | Доля скидки: 0.10 означает 10% |
| `revenue` | Выручка | Сумма продажи с учётом количества и скидки |
| `order_month` | Месяц заказа | Месяц, выделенный из даты заказа |
| `product_name` | Название товара | Человекочитаемое название товара |
| `category` | Категория | Группа товаров |
| `cost` | Себестоимость | Во сколько компании обходится единица товара |
| `region_name` | Регион | Название региона |
| `macro_region` | Макрорегион | Крупная территориальная группа |
| `segment` | Сегмент клиента | Тип клиента: B2C, B2B, Enterprise и т.д. |
| `registration_date` | Дата регистрации | Когда клиент был зарегистрирован |
| `loyalty_level` | Уровень лояльности | Bronze, Silver, Gold, Platinum |
| `orders_count` | Количество заказов | Сколько уникальных заказов попало в расчёт |
| `clients_count` | Количество клиентов | Сколько уникальных клиентов попало в расчёт |
| `total_quantity` | Общее количество | Сколько единиц товара продано всего |
| `total_revenue` | Общая выручка | Суммарная выручка по группе |
| `avg_order_revenue` | Средняя выручка на заказ | Средний размер заказа в деньгах |
| `avg_discount` | Средняя скидка | Средний размер скидки по группе |
| `discount_group` | Группа скидки | Категория скидки: без скидки, до 10%, 10–25%, выше 25% |
| `revenue_diff` | Разница в выручке | Отличие между расчётом pandas и SQL |
| `orders_diff` | Разница в заказах | Отличие в количестве заказов между pandas и SQL |

## Перевод основных действий

| Термин в коде | Русское объяснение |
|---|---|
| `DataFrame` | Таблица в pandas |
| `Series` | Один столбец таблицы pandas |
| `read_csv()` | Прочитать CSV-файл |
| `read_excel()` | Прочитать Excel-файл |
| `read_json()` | Прочитать JSON-файл |
| `head()` | Показать первые строки |
| `shape` | Размер таблицы: строки и столбцы |
| `info()` | Сводка по столбцам, типам и пропускам |
| `isna()` | Проверка пропущенных значений |
| `duplicated()` | Проверка дубликатов |
| `drop_duplicates()` | Удаление дубликатов |
| `to_datetime()` | Преобразование текста в дату |
| `str.strip()` | Удаление лишних пробелов в начале и конце текста |
| `str.lower()` | Приведение текста к нижнему регистру |
| `merge()` | Объединение таблиц по ключу |
| `groupby()` | Группировка: разделить строки на группы и посчитать показатели внутри каждой группы |
| `pivot_table()` | Сводная таблица: показатель на пересечении строк и столбцов |
| `to_csv()` | Сохранить таблицу в CSV |
| `to_excel()` | Сохранить таблицу в Excel |
| `SELECT` | Выбрать данные из SQL-таблицы |
| `WHERE` | Отфильтровать строки по условию |
| `GROUP BY` | Сгруппировать строки для расчёта показателей |
| `JOIN` | Соединить таблицы по ключу |
| `CASE` | Создать условную категорию в SQL |
| `CTE` / `WITH` | Временная именованная таблица внутри SQL-запроса |

## Как пользоваться на занятии

Когда в notebook встречается техническое имя столбца, можно открыть этот словарь и быстро посмотреть русское название. В новых версиях notebook также добавлены вспомогательные ячейки, которые выводят основные итоговые таблицы с русскими подписями столбцов.
