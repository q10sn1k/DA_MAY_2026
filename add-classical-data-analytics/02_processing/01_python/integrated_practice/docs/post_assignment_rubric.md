# Рубрика оценки пост-задания

## Общая шкала

| Уровень | Баллы | Описание |
|---|---:|---|
| Отлично | 85–100 | Работа воспроизводима, расчёты корректны, вывод осмыслен |
| Хорошо | 70–84 | Основная логика выполнена, есть незначительные недочёты |
| Требует доработки | 50–69 | Есть рабочий результат, но часть проверок или расчётов неполна |
| Не зачтено | 0–49 | Работа не запускается, отсутствует ключевая часть или результат невозможно проверить |

## Детальные критерии

| Критерий | Максимум | Что проверяется |
|---|---:|---|
| Загрузка данных | 10 | все файлы загружены, видны первые строки и размеры таблиц |
| Проверка качества | 15 | проверены типы, пропуски, дубликаты, бизнес-ошибки |
| Очистка данных | 20 | даты, текст, дубли, некорректные числа обработаны корректно |
| Объединение таблиц | 15 | выполнены `merge`, проверены строки и пропуски после объединения |
| pandas-расчёты | 15 | рассчитаны выручка, агрегаты и сводная таблица |
| SQL-запросы | 10 | есть рабочие `SELECT`, `WHERE`, `GROUP BY`, `JOIN` |
| Сверка | 5 | объяснены совпадения или расхождения pandas и SQL |
| Аналитический вывод | 10 | есть структурированный вывод и ограничение анализа |

## Причины снижения оценки

| Проблема | Снижение |
|---|---:|
| Notebook не запускается сверху вниз | до −30 |
| Используются абсолютные пути автора | до −15 |
| Нет проверки качества данных | до −20 |
| Очистка выполнена без объяснения правил | до −15 |
| Нет SQL-блока | до −10 |
| Нет аналитического вывода | до −10 |
| Итоговые файлы не сохранены | до −10 |
