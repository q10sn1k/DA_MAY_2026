# Практический комплект: преобразование, нормализация и стандартизация данных

## Назначение

Комплект сопровождает лекционный вебинар по подготовке аналитического датасета. Материалы рассчитаны на начинающих слушателей и построены вокруг сквозного кейса: подготовка данных о продажах к аналитическому отчёту.

## Быстрый запуск

1. Откройте папку проекта.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Откройте `notebooks/data_transformation_demo.ipynb`.
4. Запустите notebook сверху вниз.
5. Проверьте, что появились файлы в `data/processed/` и `outputs/`.

## Что демонстрируется

- проверка структуры файлов;
- загрузка CSV, XLSX, JSON;
- преобразование дат;
- стандартизация текстовых категорий;
- создание признаков `revenue`, `gross_margin`, `margin_rate`;
- объединение таблиц через `merge`;
- диагностика несовпавших ключей;
- агрегация через `groupby`;
- сводные таблицы через `pivot_table`;
- масштабирование признаков через MinMaxScaler, StandardScaler и RobustScaler.

## Учебные особенности данных

Данные синтетические. В них специально оставлены несколько диагностических ситуаций: нераспознанная дата, нестандартные названия каналов продаж, неизвестный товар и неизвестный клиент. Это нужно для демонстрации проверок качества.


## Пост-задание

Для закрепления материала добавлены два файла:

- `docs/post_assignment.md` — версия для слушателей: условие, шаги выполнения, критерии оценки и подсказки;
- `docs/post_assignment_teacher_key.md` — ключ проверки для преподавателя с ориентирами результата и типовыми ошибками.
