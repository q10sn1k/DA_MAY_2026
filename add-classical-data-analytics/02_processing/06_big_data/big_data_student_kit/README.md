# Комплект слушателя
## «Работа с большими данными: архитектура, хранение и масштабируемая аналитика»

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Откройте `notebooks/student_practice.ipynb`.
3. Выполняйте ячейки строго сверху вниз.
4. Используйте `data/raw/events_lite.csv`.
5. Сохраняйте результаты в `outputs`.
6. После практики выполните итоговый тест и самостоятельное задание из папки `assessment`.

Комплект не содержит решений, ключей теста и контрольных таблиц преподавателя.
