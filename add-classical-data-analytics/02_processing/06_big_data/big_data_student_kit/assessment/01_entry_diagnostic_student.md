# Входная диагностика
## «Работа с большими данными»

**Время:** 7–10 минут  
**Назначение:** определить исходный уровень. Результат не влияет на итоговую оценку.

Отметьте один или несколько вариантов в соответствии с формулировкой вопроса.

### 1. Когда данные становятся «большими»?

- А. После 1 миллиона строк.
- Б. После 1 гигабайта.
- В. Когда привычный способ обработки перестаёт удовлетворять ограничениям по памяти, времени, скорости или стоимости.
- Г. Только при использовании кластера.

### 2. Какие характеристики относятся к базовым характеристикам Big Data? Выберите четыре.

- А. Volume.
- Б. Velocity.
- В. Variety.
- Г. Variability.
- Д. Visualization.
- Е. Versioning.

### 3. Файл занимает 12 ГБ, а свободной оперативной памяти на компьютере — 8 ГБ. Какой подход наиболее рационален для первого шага?

- А. Обязательно открыть весь файл в Excel.
- Б. Прочитать только нужные столбцы и строки либо выполнить агрегацию до загрузки в память.
- В. Скопировать файл несколько раз.
- Г. Удалить случайную часть строк.

### 4. Какое утверждение о CSV наиболее точное?

- А. CSV всегда хранит строгую схему и типы данных.
- Б. CSV является текстовым форматом; типы, разделитель и кодировку необходимо проверять.
- В. CSV предназначен только для изображений.
- Г. CSV нельзя читать из Python.

### 5. Какое утверждение о Parquet наиболее точное?

- А. Это колоночный формат, удобный для аналитических запросов.
- Б. Это графический формат.
- В. Он всегда быстрее любого другого формата при любом запросе.
- Г. Он не поддерживает сжатие.

### 6. Что обычно лучше выполнить раньше при работе с крупными данными?

- А. Передать все строки в библиотеку визуализации.
- Б. Отфильтровать строки, выбрать нужные поля и агрегировать результат.
- В. Построить график без проверки данных.
- Г. Переименовать файл.

### 7. Что такое партиция данных?

- А. Часть набора, которую можно обрабатывать как отдельный фрагмент.
- Б. Название диаграммы.
- В. Ошибка подключения.
- Г. Только резервная копия.

### 8. Какая операция чаще требует перераспределения данных между вычислителями?

- А. Локальная фильтрация строк.
- Б. Глобальная группировка по ключу, значения которого распределены между партициями.
- В. Просмотр имени файла.
- Г. Проверка версии Python.

### 9. В каком случае потоковая обработка обоснована сильнее всего?

- А. Ежемесячный архивный отчёт.
- Б. Выявление подозрительной операции с минимальной задержкой.
- В. Однократный пересчёт истории за прошлый год.
- Г. Подготовка статичного учебного файла.
