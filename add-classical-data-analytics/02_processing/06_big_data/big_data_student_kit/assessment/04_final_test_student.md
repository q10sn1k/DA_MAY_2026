# Итоговый тест
## «Работа с большими данными»

**Время:** 15–20 минут  
**Максимум:** 20 баллов  
В вопросах с пометкой «несколько ответов» нужно выбрать все правильные варианты.

### 1. Какое определение Big Data наиболее корректно?

- А. Любая таблица, содержащая более 1 миллиона строк.
- Б. Данные, для обработки которых требуются масштабируемые подходы из-за ограничений объёма, скорости, разнообразия или изменчивости.
- В. Только данные социальных сетей.
- Г. Любой файл Parquet.

### 2. Какие четыре характеристики образуют базовую модель 4V? Несколько ответов.

- А. Volume.
- Б. Velocity.
- В. Variety.
- Г. Variability.
- Д. Visualization.
- Е. Validation.

### 3. Сервис получает 30 тысяч событий каждую секунду. Какая характеристика наиболее явно проявляется?

- А. Volume.
- Б. Velocity.
- В. Variety.
- Г. Variability.

### 4. Что означает горизонтальное масштабирование?

- А. Увеличение памяти одной машины.
- Б. Добавление вычислительных узлов и распределение работы.
- В. Уменьшение числа строк.
- Г. Перевод CSV в XLSX.

### 5. Какова основная роль driver в распределённом приложении Spark?

- А. Координировать план и выполнение приложения.
- Б. Обязательно хранить все исходные данные в своей памяти.
- В. Выполнять только визуализацию.
- Г. Заменять файловое хранилище.

### 6. Что такое партиция?

- А. Логический или физический фрагмент данных, который может обрабатываться отдельно.
- Б. Готовый дашборд.
- В. Пароль к базе.
- Г. Тип диаграммы.

### 7. Что в Spark называется shuffle?

- А. Переименование колонок.
- Б. Перераспределение данных между партициями для новой группировки или объединения.
- В. Установка библиотеки.
- Г. Сохранение скриншота.

### 8. Какой порядок слоёв данных наиболее логичен?

- А. Витрина → raw → очищенные данные.
- Б. Raw → очищенные данные → аналитическая витрина.
- В. График → CSV → raw.
- Г. Отчёт → источник → API.

### 9. Какое свойство CSV требует обязательной проверки?

- А. CSV всегда содержит строгие типы.
- Б. Разделитель, кодировка и распознанные типы могут отличаться.
- В. CSV не содержит строк.
- Г. CSV всегда сжат.

### 10. Какие свойства характерны для Parquet? Несколько ответов.

- А. Колоночное хранение.
- Б. Поддержка компрессии.
- В. Удобство выбора части колонок.
- Г. Гарантированное ускорение любого запроса.
- Д. Хранение схемы.

### 11. Что означает projection pushdown?

- А. Движок читает только необходимые запросу колонки.
- Б. Все колонки копируются в pandas.
- В. Файл разделяется случайным образом.
- Г. Удаляются все строки с пропусками.

### 12. Какой запрос лучше соответствует принципу раннего сокращения данных?

- А. `SELECT * FROM events` с последующей фильтрацией в Python.
- Б. `SELECT event_date, region, SUM(price * quantity) FROM events WHERE event_type='purchase' GROUP BY event_date, region`.
- В. `SELECT * FROM events` без условий.
- Г. Копирование файла перед каждым расчётом.

### 13. Какой ключ чаще подходит для файлового партиционирования событий?

- А. `event_date`, если запросы регулярно фильтруют период.
- Б. `event_id`, уникальный почти для каждой строки.
- В. Случайное число.
- Г. Полный текст комментария.

### 14. Какая задача обычно лучше соответствует пакетной обработке?

- А. Выявление подозрительной транзакции за секунды.
- Б. Ночной перерасчёт ежедневной витрины.
- В. Реакция на аварийный датчик в реальном времени.
- Г. Обновление статуса онлайн-сессии после каждого события.

### 15. Какие утверждения о Kafka корректны? Несколько ответов.

- А. Producer публикует события.
- Б. Consumer читает и обрабатывает события.
- В. Topic логически объединяет поток событий.
- Г. Kafka автоматически исправляет любые бизнес-ошибки в данных.

### 16. Почему нельзя автоматически удалять все повторяющиеся строки?

- А. Дубликаты всегда полезны.
- Б. Сначала нужно определить ключ, гранулярность и бизнес-правило выбора записи.
- В. SQL не умеет удалять дубли.
- Г. Parquet запрещает очистку.

### 17. Когда показатель `AVG(price * quantity)` можно интерпретировать как средний чек?

- А. Всегда.
- Б. Только если одна строка соответствует одному заказу или сначала выполнена агрегация до уровня заказа.
- В. Только для CSV.
- Г. Если строк больше миллиона.

### 18. Как корректнее рассчитать пользовательскую конверсию из просмотра в покупку?

- А. Разделить количество событий покупки на количество событий просмотра.
- Б. Разделить число пользователей, совершивших покупку после наличия просмотра, на число пользователей с просмотром.
- В. Разделить сумму покупок на число регионов.
- Г. Посчитать среднюю цену.

### 19. Для чего используется `EXPLAIN ANALYZE`?

- А. Для выполнения запроса и просмотра фактического плана и показателей операторов.
- Б. Для установки DuckDB.
- В. Для изменения кодировки файла.
- Г. Для создания презентации.

### 20. В регионе обнаружен резкий рост событий, но сумма покупок не выросла. Какой вывод наиболее корректен?

- А. Продажи точно выросли.
- Б. Рост активности не равен росту покупок; нужно проверить состав событий, источники трафика и возможные технические всплески.
- В. Данные нужно удалить.
- Г. Регион следует исключить без проверки.
