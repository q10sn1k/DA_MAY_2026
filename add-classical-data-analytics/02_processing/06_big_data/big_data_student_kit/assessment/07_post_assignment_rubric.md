# Критерии оценивания самостоятельной работы

**Максимум:** 20 баллов.

| Критерий | Максимум | Требования |
|---|---:|---|
| Воспроизводимость и структура | 2 | Notebook запускается сверху вниз; относительные пути; понятная структура файлов |
| Профилирование качества | 3 | Проверены схема, типы, пропуски, дубли, диапазоны и бизнес-аномалии |
| Обоснованная очистка | 3 | Правила описаны; число строк до/после зафиксировано; исходник не повреждён |
| Parquet и партиционирование | 3 | Создан Parquet; выполнено сравнение размеров; ключ партиции обоснован |
| Аналитические расчёты | 4 | Все обязательные KPI рассчитаны корректно и проверены |
| Визуализации | 2 | Не менее трёх читаемых графиков с корректной агрегацией |
| Витрина | 1 | Создан `daily_region_device_metrics.parquet` требуемой гранулярности |
| Выводы и ограничения | 2 | Не менее трёх выводов с числами и не менее двух ограничений |

## Правила снижения оценки

- Ошибка, из-за которой notebook не запускается сверху вниз: не более 12 баллов до исправления.
- Абсолютные пути автора: минус 1 балл.
- Отсутствие объяснения удаления дублей: минус до 2 баллов.
- Выводы без числового подтверждения: 0 баллов за соответствующий критерий.
- Подмена пользовательской конверсии отношением числа событий: минус 1 балл в блоке расчётов.
- Партиционирование по почти уникальному идентификатору без обоснования: 0 баллов за соответствующую часть.

## Интерпретация

| Баллы | Результат |
|---:|---|
| 18–20 | Работа выполнена на высоком уровне |
| 15–17 | Работа выполнена корректно, есть небольшие замечания |
| 12–14 | Базовый результат достигнут, требуется доработка отдельных элементов |
| 0–11 | Работа требует существенной доработки |

Рекомендуемый порог зачёта: **12 баллов**.
