# Словарь данных

| Поле | Тип | Назначение | Пример |
|---|---|---|---|
| `event_id` | string | Идентификатор события | `EV-000000001` |
| `event_time` | timestamp | Дата и время события | `2026-07-14 12:05:31` |
| `event_date` | date | Дата для анализа и партиционирования | `2026-07-14` |
| `user_id` | string | Синтетический пользователь | `U-000123` |
| `session_id` | string | Синтетическая сессия | `S-0000456` |
| `event_type` | string | Тип действия | `view`, `purchase` |
| `product_id` | string | Идентификатор товара | `P-0042` |
| `category` | string | Категория товара | `Электроника` |
| `region` | string | Регион события | `Москва` |
| `device` | string | Тип устройства | `mobile` |
| `quantity` | integer | Количество единиц | `2` |
| `price` | decimal | Цена единицы | `15990.00` |
| `response_ms` | integer | Время ответа системы, мс | `245` |

## Гранулярность

Одна строка соответствует одному событию пользователя. Событие `purchase` не гарантирует, что строка равна полному заказу: в наборе отсутствует `order_id`. Поэтому `AVG(price * quantity)` — среднее значение события покупки, а не доказанный средний чек заказа.

## Контролируемые особенности

Ошибки добавлены намеренно для учебной проверки качества. Их точные количества находятся в `control_values.json` и предназначены для преподавателя.
