# Инструкция слушателя
## Практическая работа «Обработка крупных наборов событий с помощью DuckDB и Parquet»

## Результат

После выполнения должны быть созданы:

```text
data/processed/events.parquet
data/processed/events_by_date/
outputs/events_by_type.csv
outputs/purchases_by_region.csv
outputs/daily_metrics.csv
outputs/daily_region_metrics.parquet
outputs/region_analysis.csv
```

## Запуск

```bash
python -m pip install -r requirements.txt
jupyter lab
```

Откройте `notebooks/student_practice.ipynb` и выполняйте ячейки сверху вниз.

## Рабочая последовательность

1. Проверить версии Python и библиотек.
2. Найти корень проекта и исходный CSV.
3. Проверить количество строк и схему.
4. Исследовать пропуски, дубликаты и отрицательные значения.
5. Применить правила очистки, не изменяя исходный файл.
6. Сохранить очищенные данные в Parquet.
7. Сверить число строк и размеры файлов.
8. Рассчитать события, пользователей, сессии, покупки и конверсию.
9. Построить две визуализации по агрегированным таблицам.
10. Создать партиционированный набор по дате.
11. Сформировать аналитическую витрину.
12. Выполнить анализ выбранного региона.
13. Сформулировать два вывода и одно ограничение.
14. Перезапустить ядро и выполнить весь notebook сверху вниз.

## Требования к выводам

Каждый вывод должен содержать:

- наблюдение;
- числовое подтверждение;
- интерпретацию;
- ограничение или следующий шаг.
