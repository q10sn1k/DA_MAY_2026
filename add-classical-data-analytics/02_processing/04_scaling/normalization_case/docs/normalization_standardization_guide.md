# Нормализация и стандартизация данных перед аналитическим отчётом

## Назначение

Этот документ описывает второй практический комплект. Его задача — превратить результаты входного аудита данных в подготовленную аналитическую витрину.

## Что считается нормализацией в этом кейсе

Нормализация в рамках практики — это приведение значений к единому представлению:

- удаление лишних пробелов в текстовых полях;
- единый регистр ключей и категорий;
- единые названия каналов продаж;
- единый формат дат;
- разрешение дублей в справочниках;
- подготовка сопоставимых категорий для группировки.

## Что считается стандартизацией в этом кейсе

Стандартизация — это подготовка числовых признаков к сопоставлению:

- расчёт выручки по единой формуле;
- расчёт маржи по единой формуле;
- z-score стандартизация выручки;
- min-max нормализация выручки в диапазон от 0 до 1.

## Основной принцип

Не нужно исправлять данные молча. Любое исключение строки, нормализация поля или разрешение дубля должно быть отражено в логе трансформаций.
