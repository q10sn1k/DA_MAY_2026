# Самостоятельное закрепление после семинара

## Название

Подготовка итогового аналитического вывода по качеству и витрине данных

## Цель

Закрепить умение переходить от технической обработки данных к понятному аналитическому выводу.

## Исходная ситуация

Вы подготовили витрину продаж и сверили результаты Python и R. Теперь нужно оформить короткий отчёт для руководителя, который не читает код, но должен понять качество данных, ограничения и основные показатели.

## Что нужно сделать

1. Откройте итоговые файлы в папке `outputs`.
2. Посмотрите `data_quality_issues.csv`.
3. Посмотрите `sales_datamart.csv`.
4. Посмотрите `report_by_region_channel.csv`.
5. Посмотрите `final_python_r_comparison.csv`.
6. Подготовьте короткий отчёт на 1 страницу.

## Структура отчёта

1. Какие данные использовались.
2. Какие основные проблемы качества были найдены.
3. Какие строки или проблемы были исключены из расчёта.
4. Какая итоговая выручка и маржа получились.
5. Какие регионы или каналы стоит посмотреть внимательнее.
6. Совпали ли результаты Python и R.
7. Какие ограничения нужно учитывать.
8. Что нужно сделать следующим шагом.

## Формат сдачи

Файл `.md`, `.docx` или `.pdf` с коротким аналитическим отчётом. Код прикладывать не нужно, но можно приложить итоговые таблицы.

## Критерии оценки

| Критерий | Что проверяется |
|---|---|
| Структура | Отчёт читается как управленческий вывод, а не как список команд |
| Конкретика | Указаны реальные проблемы и показатели |
| Ограничения | Есть честное описание качества данных |
| Вывод | Есть решение: можно ли использовать витрину и что делать дальше |
| Читаемость | Текст понятен человеку без знания Python и R |
