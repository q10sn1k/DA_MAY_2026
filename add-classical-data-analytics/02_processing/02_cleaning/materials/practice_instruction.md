## Главное правило работы

**Запускайте ячейки строго сверху вниз.**

Не пропускайте ячейки.  
Не запускайте ячейки в случайном порядке.  
Не удаляйте код из notebook.  
Если появилась ошибка, остановитесь и сообщите преподавателю.

Почему это важно:

- одни ячейки создают переменные;
- другие ячейки используют эти переменные;
- если пропустить ячейку, следующая часть notebook может не работать;
- если запускать ячейки в случайном порядке, можно получить ошибку или неправильный результат.

## Что делать, если notebook не запускается

### Ошибка: `ModuleNotFoundError`

Это значит, что не установлена нужная библиотека.

Пример ошибки:

```text
ModuleNotFoundError: No module named 'pandas'
```

Попробуйте выполнить в отдельной ячейке:

```python
%pip install pandas numpy matplotlib openpyxl
```

После установки перезапустите ячейку, где возникла ошибка.

---

### Ошибка при работе с Excel

Если появляется ошибка, связанная с файлами `.xlsx`, выполните:

```python
%pip install openpyxl
```

После установки повторите запуск ячейки.

---

### Ошибка: `FileNotFoundError`

Это значит, что Python не нашёл файл.

В этом notebook нужные файлы создаются автоматически. Поэтому чаще всего причина такая:

- ячейки запускались не сверху вниз;
- была пропущена часть, где создаются данные;
- notebook был перезапущен, но предыдущие ячейки не выполнены.

Решение:

1. Вернитесь в начало notebook.
2. Запустите ячейки сверху вниз.
3. Не пропускайте блок создания данных.

---

### Ошибка: `NameError`

Это значит, что переменная ещё не создана.

Например, если Python пишет, что не знает переменную `sales_full`, значит ячейка, где создаётся `sales_full`, ещё не была выполнена.

Решение:

1. Найдите ячейку, где создаётся нужная переменная.
2. Запустите её.
3. Затем снова запустите ячейку, где была ошибка.

---

### Ошибка: `KeyError`

Это значит, что Python не нашёл нужный столбец в таблице.

Например:

```text
KeyError: 'revenue'
```

Возможные причины:

- столбец ещё не создан;
- ячейка с расчётом столбца не была выполнена;
- название столбца написано с ошибкой;
- в названии есть лишний пробел.

Для проверки названий столбцов используйте:

```python
df.columns.tolist()
```
