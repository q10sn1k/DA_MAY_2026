# Резервная инструкция для LMS: SQL без Docker и MySQL

## Когда использовать этот файл

Открывайте файл `00_sqlite_backup_no_docker_no_mysql.ipynb`, если на компьютере слушателя:

- нет Docker;
- нет MySQL;
- нет прав администратора на установку программ;
- MySQL не запускается;
- Docker Desktop не установлен или не работает.

## Что понадобится

- Python;
- Jupyter Notebook, JupyterLab или Google Colab;
- библиотека `pandas`.

Модуль `sqlite3` входит в стандартную библиотеку Python, отдельно устанавливать его не нужно.

## Что изучаем

В резервном ноутбуке слушатели выполняют те же учебные темы:

1. создание таблицы `users`;
2. добавление строк через `INSERT`;
3. выборка данных через `SELECT`;
4. фильтрация через `WHERE`;
5. сортировка через `ORDER BY`;
6. агрегаты `COUNT`, `AVG`, `SUM`, `MIN`, `MAX`;
7. обновление и удаление данных;
8. таблица `orders`;
9. внешний ключ;
10. подзапросы;
11. `UNION`;
12. `INNER JOIN` и `LEFT JOIN`;
13. выгрузка SQL-запроса в pandas `DataFrame`.

## Как объяснить слушателям

SQLite — это учебная локальная база данных. Она не требует отдельного сервера и создаёт базу как обычный файл `.db`.

Мы используем SQLite не потому, что она полностью заменяет MySQL, а потому что она позволяет изучить базовую SQL-логику без установки дополнительного ПО.

## Какой порядок работы

1. Открыть `00_sqlite_backup_no_docker_no_mysql.ipynb`.
2. Запустить ячейки сверху вниз.
3. После демонстрационных блоков выполнить задания.
4. Проверить себя по блоку решений.
5. После занятия при наличии Docker/MySQL повторить основной сценарий в MySQL.

## Главное отличие от MySQL

В SQLite не нужны команды:

```sql
CREATE DATABASE my_database;
USE my_database;
```

База создаётся строкой Python:

```python
connection = sqlite3.connect("seminar_sqlite_backup.db")
```

## Комментарий для преподавателя

Если группа технически неоднородная, можно работать параллельно:

- слушатели с Docker/MySQL идут по основным файлам;
- слушатели без Docker/MySQL открывают SQLite-резерв;
- преподаватель объясняет SQL-команды универсально, а различия синтаксиса проговаривает отдельно.
