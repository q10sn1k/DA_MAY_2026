# Инструкция для практической работы

## Рабочая ситуация
Вы аналитик, который подключается к проекту интернет-магазина. Руководитель хочет понять, почему меняется выручка, какие товары продаются лучше, какие каналы приводят клиентов и где могут быть проблемы с данными.

## Что нужно сделать
1. Откройте `csv/business_questions.csv`.
2. Выберите один или несколько источников данных для каждого бизнес-вопроса.
3. Используйте `csv/source_catalog.csv` и `csv/data_dictionary.csv`, чтобы понять назначение файлов и ключевые поля.
4. Заполните карту источников данных.
5. Выберите один источник и заполните паспорт источника.
6. Напишите короткий вывод на 5–7 предложений.

## Что считать хорошим результатом
- Источник связан с конкретным бизнес-вопросом.
- Указан владелец или предполагаемый владелец.
- Зафиксированы формат, структура, ключевые поля и период обновления.
- Найдены риски качества.
- Указано, какие проверки нужны перед анализом.
- Итог можно передать другому аналитику без устных пояснений.
