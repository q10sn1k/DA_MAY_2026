# Практический набор CSV для вебинара «Типы и источники данных»

## Назначение
Папка содержит синтетические данные небольшого интернет-магазина. Набор нужен не для сложных расчетов, а для практики по теме источников данных: выбрать источник под бизнес-вопрос, классифицировать данные, указать владельца, формат, ключевые поля, риски качества и проверки перед анализом.

## Как открыть
CSV-файлы сохранены в кодировке UTF-8 с BOM и разделителем `;`, чтобы их было проще открыть в Excel на русской локали.

В Python / pandas использовать:
```python
import pandas as pd
sales = pd.read_csv('csv/sales.csv', sep=';')
```

## Файлы для слушателей
- `business_questions.csv` — вопросы руководителя для практики.
- `source_catalog.csv` — каталог доступных источников.
- `data_dictionary.csv` — словарь полей по каждому CSV.
- `sales.csv` — таблица продаж.
- `products.csv` — справочник товаров.
- `clients.csv` — таблица клиентов.
- `regions.csv` — справочник регионов.
- `marketing_channels.csv` — выгрузка рекламных каналов.
- `site_events_log.csv` — лог событий сайта, выгруженный в табличный CSV.
- `customer_reviews.csv` — отзывы клиентов.
- `external_source_links.csv` — ссылки на реальные внешние источники для демонстрации.

## Задание для слушателей
1. Открыть `business_questions.csv`.
2. Для каждого вопроса выбрать подходящие источники из `source_catalog.csv`.
3. Заполнить карту источников данных в шаблоне.
4. Для одного источника заполнить паспорт источника.
5. В выводе указать: какие данные можно использовать сразу, какие требуют проверки, каких данных не хватает.

## Контролируемые проблемы качества
В данных специально оставлены учебные проблемы: дубли, пропуски, разные написания каналов, несовпадение периодов, неизвестные ключи справочников и спорные значения. Это сделано намеренно, чтобы слушатели учились проверять пригодность источника до анализа.

Для преподавателя: подробный список проблем лежит в `teacher/teacher_quality_issues_key.csv`.
