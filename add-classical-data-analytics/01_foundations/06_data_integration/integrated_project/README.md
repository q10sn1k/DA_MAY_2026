# Учебный комплект: загрузка и интеграция данных из различных форматов

## 1. Назначение комплекта

Учебный комплект подготовлен для занятия по теме:

**«Загрузка и интеграция данных из различных форматов. Инструменты для сбора данных. Основы Python для обработки данных»**

Комплект предназначен для слушателей программы профессиональной переподготовки **«Аналитик данных»** и рассчитан на начальный уровень подготовки.

Главная идея занятия: показать полный рабочий цикл аналитика данных — от получения файлов из разных источников до подготовки единой аналитической таблицы, первичного анализа, визуализации и сохранения результата.

На занятии слушатели работают с учебным кейсом **«РегионМаркет»**: компания продает товары в разных регионах, а данные приходят из разных источников — CSV, Excel, JSON и HTML-таблицы.

---

## 2. Учебные цели

После занятия слушатель должен уметь:

- открывать учебный проект и запускать Jupyter Notebook;
- загружать данные из CSV, Excel, JSON и HTML;
- проверять структуру таблицы через `head()`, `shape`, `info()`, `dtypes`;
- находить пропуски, дубликаты и некорректные значения;
- приводить типы данных: даты, числа, текстовые поля;
- очищать строковые значения от лишних пробелов и разного регистра;
- объединять несколько таблиц через `merge()`;
- создавать расчетные показатели;
- выполнять группировки и сводные таблицы;
- строить базовые графики;
- сохранять результат в CSV, Excel, Parquet и DuckDB;
- понимать, как передать подготовленные данные из Python в R.

## 6. Порядок запуска

### Шаг 1. Распаковать архив

Распакуйте архив с материалами в удобную папку, например:

```text
C:\data_course\data_loading_integration_python
```

или на macOS/Linux:

```text
~/data_course/data_loading_integration_python
```

### Шаг 2. Открыть терминал в папке проекта

Перейдите в корневую папку проекта:

```bash
cd data_loading_integration_python
```

### Шаг 3. Создать виртуальное окружение

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Шаг 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### Шаг 5. Проверить окружение

```bash
python environment_check.py
```

Ожидаемый результат: скрипт выводит версии установленных библиотек и сообщение, что окружение готово.

### Шаг 6. Запустить JupyterLab

```bash
jupyter lab
```

После запуска откройте папку:

```text
notebooks_student/
```

и начните с ноутбука:

```text
00_setup_and_check.ipynb
```

## 7. Данные проекта

Исходные данные находятся в папке:

```text
data/raw/
```

| Файл | Формат | Назначение |
|---|---|---|
| `sales.csv` | CSV | Основная таблица продаж |
| `products.xlsx` | Excel | Справочник товаров |
| `regions.json` | JSON | Справочник регионов |
| `clients.csv` | CSV | Справочник клиентов |
| `web_table_sample.html` | HTML | Локальная HTML-таблица с планами продаж |

В датасеты специально заложены учебные проблемы:

- пропуски;
- дубликаты;
- разные форматы дат;
- числовые значения, записанные как текст;
- лишние пробелы;
- разные регистры написания;
- несовпадающие ключи между таблицами;
- ошибочные значения, например отрицательное количество или скидка больше 100%.

Эти ошибки нужны для учебной практики по очистке и проверке качества данных.

## 8. Список учебных ноутбуков

### `00_setup_and_check.ipynb`

Проверка среды и готовности проекта.

Слушатель проверяет:

- запуск Python;
- импорт библиотек;
- текущую рабочую папку;
- доступность файлов данных;
- чтение тестового CSV.

### `01_data_loading_formats.ipynb`

Загрузка данных из разных форматов.

Темы:

- `pd.read_csv()`;
- `pd.read_excel()`;
- `pd.read_json()`;
- `pd.read_html()`;
- параметры `sep`, `encoding`, `sheet_name`, `header`;
- сохранение данных в CSV и Excel.

### `02_dataframe_types_and_quality.ipynb`

Проверка структуры и качества данных.

Темы:

- `DataFrame` и `Series`;
- `head()`, `tail()`, `shape`, `columns`;
- `info()`, `dtypes`;
- пропуски;
- дубликаты;
- преобразование типов;
- обработка строк;
- преобразование дат.

### `03_data_integration.ipynb`

Интеграция нескольких источников данных.

Темы:

- объединение `sales.csv` и `products.xlsx`;
- объединение с `regions.json`;
- объединение с `clients.csv`;
- `left join`, `inner join`, `outer join`;
- проверка результата после `merge()`;
- сохранение подготовленной таблицы `sales_prepared.csv`.

### `04_basic_analysis.ipynb`

Базовый анализ подготовленных данных.

Темы:

- фильтрация;
- сортировка;
- создание расчетного поля `revenue`;
- `groupby()`;
- агрегаты;
- `pivot_table()`;
- `describe()`;
- сохранение аналитического результата.

### `05_basic_visualization.ipynb`

Первичная визуализация.

Темы:

- динамика продаж;
- продажи по категориям;
- топ регионов;
- распределение чеков;
- boxplot;
- scatter plot.

### `06_python_to_r_bridge.ipynb`

Передача результата из Python в R.

Темы:

- сохранение в CSV;
- сохранение в Excel;
- сохранение в Parquet;
- сохранение в DuckDB;
- чтение результата в R.

### `07_final_practice_case.ipynb`

Итоговый практический кейс.

Слушатель самостоятельно выполняет полный цикл:

1. загружает все исходные файлы;
2. проверяет структуру данных;
3. очищает проблемные поля;
4. объединяет таблицы;
5. создает расчетные показатели;
6. строит сводные таблицы;
7. строит графики;
8. сохраняет результат;
9. формулирует аналитические выводы.

## 10. Ожидаемый результат занятия

К концу занятия слушатель должен получить:

```text

```

и, в зависимости от выполненных блоков:

Итоговый результат — единая аналитическая таблица, в которой продажи обогащены данными о товарах, регионах, клиентах и планах продаж.

- какая общая выручка компании;
- какие категории дают максимальную выручку;
- какие регионы лидируют по продажам;
- какой канал продаж наиболее эффективен;
- какие строки не удалось корректно объединить со справочниками;
- где есть проблемы качества данных;
- какие регионы или каналы не выполняют план.

### Что должно быть подготовлено заранее

- обращение к внешним API;

- установка пакетов во время занятия;
- работа с облачными средами без заранее подготовленных аккаунтов.

### Чем заменяются внешние источники

| Внешний источник | Офлайн-замена |
|---|---|
| API | локальный JSON-файл `regions.json` |

## 13. Работа с R

Блок Python → R является дополнительным.

Основная идея:

```text
Python загружает, очищает и объединяет данные
↓
результат сохраняется в CSV / Excel / Parquet / DuckDB
↓
R читает подготовленный результат
↓
в R можно продолжить анализ, визуализацию или подготовку отчета
```

R-скрипты находятся в папке:

```text
r/
```

Файлы:

- `install_packages.R`;
- `01_read_python_result.R`;
- `02_duckdb_from_r.R`;
- `03_basic_r_visualization.R`.

Если R не установлен у слушателей, этот блок можно показать демонстрационно только на компьютере лектора.
