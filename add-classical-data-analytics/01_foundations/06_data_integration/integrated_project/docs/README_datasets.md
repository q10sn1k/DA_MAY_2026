# Учебные датасеты «РегионМаркет»

Комплект предназначен для занятия «Загрузка и интеграция данных из различных форматов. Инструменты для сбора данных. Основы Python для обработки данных».

## Состав файлов

- `sales.csv` — факты продаж: CSV с проблемами дат, числовых типов, дубликатов, пропусков и несовпадающих ключей.
- `products.xlsx` — справочник товаров: Excel с листами `products`, `category_reference`, `dataset_issues`.
- `regions.json` — справочник регионов: JSON со строковыми проблемами и пропуском.
- `clients.csv` — справочник клиентов: CSV с разными форматами дат, дубликатами и пропусками.
- `web_table_sample.html` — локальная HTML-таблица с планом продаж.

## Основные связи

- `sales.product_id` → `products.product_id`
- `sales.region_id` → `regions.region_id`
- `sales.client_id` → `clients.client_id`
- `sales.region_id + sales.channel + month(order_date)` → `plan.region_id + plan.channel + plan.month`

## Учебные задачи

1. Загрузить данные из CSV, Excel, JSON и HTML.
2. Проверить типы, пропуски и дубликаты.
3. Очистить текстовые поля от пробелов и разного регистра.
4. Преобразовать даты и числовые поля.
5. Объединить таблицы через `merge`.
6. Найти строки, которые не смогли обогатиться справочниками.
7. Рассчитать выручку, скидку, себестоимость и прибыль.
8. Сравнить факт с планом.
