# Раздатка: pivot_table для начинающих

## Тема

**Сводные таблицы в pandas: `pivot_table()`**

Эта раздатка предназначена для слушателей начального уровня.  
Цель — понять, что такое сводная таблица, чем она отличается от обычной группировки `groupby()`, когда ее использовать и как работают параметры:

```text
index
columns
values
aggfunc
fill_value
```

---

# 1. Зачем нужна сводная таблица

Когда аналитик работает с продажами, ему часто нужно получить итог не просто по одной группе, а сразу в виде **таблицы пересечения двух признаков**.

Например, есть продажи:

| sale_id | region_name | category | revenue |
|---:|---|---|---:|
| 1 | Москва | электроника | 120000 |
| 2 | Москва | одежда | 15000 |
| 3 | Казань | электроника | 60000 |
| 4 | Казань | мебель | 30000 |
| 5 | Москва | мебель | 50000 |

Бизнес-вопрос:

> сколько выручки принесла каждая категория в каждом регионе?

Удобный итог:

| region_name | мебель | одежда | электроника |
|---|---:|---:|---:|
| Казань | 30000 | 0 | 60000 |
| Москва | 50000 | 15000 | 120000 |

Это и есть сводная таблица.

---

# 2. Бытовая аналогия

Представьте школьный журнал.

В строках — ученики.  
В столбцах — предметы.  
В ячейках — оценки.

| Ученик | Математика | Русский | История |
|---|---:|---:|---:|
| Анна | 5 | 4 | 5 |
| Иван | 3 | 4 | 4 |

Сводная таблица работает похожим образом:

- строки — один признак;
- столбцы — второй признак;
- внутри ячеек — рассчитанный показатель.

В аналитике продаж:

- строки — регионы;
- столбцы — категории;
- ячейки — сумма выручки.

---

# 3. Главное отличие pivot_table от groupby

## 3.1. groupby

`groupby()` обычно дает длинную итоговую таблицу.

Пример:

```python
df.groupby(["region_name", "category"], as_index=False).agg(
    total_revenue=("revenue", "sum")
)
```

Результат:

| region_name | category | total_revenue |
|---|---|---:|
| Казань | мебель | 30000 |
| Казань | электроника | 60000 |
| Москва | мебель | 50000 |
| Москва | одежда | 15000 |
| Москва | электроника | 120000 |

Это удобно для дальнейшей обработки и фильтрации.

---

## 3.2. pivot_table

`pivot_table()` дает широкую таблицу, похожую на сводную таблицу Excel.

Пример:

```python
pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum",
    fill_value=0
)
```

Результат:

| region_name | мебель | одежда | электроника |
|---|---:|---:|---:|
| Казань | 30000 | 0 | 60000 |
| Москва | 50000 | 15000 | 120000 |

Это удобно для сравнения пересечений: регион × категория, канал × месяц, клиентский тип × категория.

---

# 4. Простое правило выбора

| Задача | Что использовать |
|---|---|
| Посчитать показатель по одной группе | `groupby()` |
| Посчитать показатель по нескольким группам в длинном виде | `groupby()` |
| Получить таблицу пересечения строк и столбцов | `pivot_table()` |
| Сделать аналог сводной таблицы Excel | `pivot_table()` |
| Подготовить данные для графика с одной осью категорий | чаще `groupby()` |
| Сравнить регионы по категориям в виде матрицы | `pivot_table()` |

# 5. Мини-пример

Создадим учебную таблицу.

```python
import pandas as pd

df = pd.DataFrame({
    "sale_id": [1, 2, 3, 4, 5, 6],
    "region_name": ["Москва", "Москва", "Казань", "Казань", "Москва", "Казань"],
    "category": ["электроника", "одежда", "электроника", "мебель", "мебель", "одежда"],
    "channel": ["online", "offline", "online", "marketplace", "online", "offline"],
    "revenue": [120000, 15000, 60000, 30000, 50000, 10000],
})
```

Посмотрим таблицу:

```python
df
```

# 6. Базовый синтаксис pivot_table

```python
pivot = pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum",
    fill_value=0
)

pivot
```

Читается так:

```text
взять таблицу df
↓
в ячейках считать revenue
↓
строки сделать по region_name
↓
столбцы сделать по category
↓
внутри каждой ячейки сложить значения
↓
пустые комбинации заменить на 0
```

# 7. Параметр index

## 7.1. Что такое index

`index` — это то, что будет в строках сводной таблицы.

Пример:

```python
index="region_name"
```

Означает:

> каждая строка итоговой таблицы — отдельный регион.

```python
pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum",
    fill_value=0
)
```

Результат:

| region_name | мебель | одежда | электроника |
|---|---:|---:|---:|
| Казань | 30000 | 10000 | 60000 |
| Москва | 50000 | 15000 | 120000 |

---

## 7.2. Несколько полей в index

Можно указать несколько полей:

```python
pd.pivot_table(
    df,
    values="revenue",
    index=["region_name", "channel"],
    columns="category",
    aggfunc="sum",
    fill_value=0
)
```

Это значит:

> строки будут строиться по комбинации регион + канал.

---

# 8. Параметр columns

## 8.1. Что такое columns

`columns` — это то, что будет в столбцах сводной таблицы.

Пример:

```python
columns="category"
```

Означает:

> каждая категория станет отдельным столбцом.

```python
pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum",
    fill_value=0
)
```

---

## 8.2. Когда columns особенно полезен

Используйте `columns`, когда нужно сравнить группы бок о бок.

Примеры:

| Строки `index` | Столбцы `columns` | Что сравниваем |
|---|---|---|
| `region_name` | `category` | категории внутри регионов |
| `month` | `channel` | каналы по месяцам |
| `client_type` | `category` | категории по типам клиентов |
| `region_name` | `channel` | каналы продаж по регионам |

# 9. Параметр values

Пример:

```python
values="revenue"
```

Означает:

> в ячейках будет рассчитана выручка.

```python
pd.pivot_table(
    df,

)
```

---

## 9.2. Примеры values

| Что хотим посчитать | values |
|---|---|
| Выручка | `"revenue"` |
| Валовая прибыль | `"gross_profit"` |
| Количество товаров | `"quantity"` |
| Скидка | `"discount_percent"` |
| Номер заказа для подсчета заказов | `"sale_id"` |

# 10. Параметр aggfunc

## 10.1. Что такое aggfunc

`aggfunc` — это функция расчета.

Она отвечает на вопрос:

> что делать со значениями внутри каждой ячейки?

Например, если в Москве по категории «электроника» было 10 продаж, нужно понять:

- сложить выручку;
- посчитать среднюю выручку;
- посчитать количество продаж;
- найти максимум;
- найти минимум.

---

## 10.2. Частые значения aggfunc

| aggfunc | Что делает | Когда использовать |
|---|---|---|
| `"sum"` | сумма | общая выручка, прибыль, количество |
| `"mean"` | среднее | средний чек, средняя скидка |
| `"count"` | количество непустых значений | количество строк |
| `"nunique"` | количество уникальных значений | количество уникальных заказов |
| `"min"` | минимум | минимальный чек |
| `"max"` | максимум | максимальный чек |
| `"median"` | медиана | типичное значение без сильного влияния выбросов |

---

## 10.3. Пример: сумма выручки

```python
pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum",
    fill_value=0
)
```

---

## 10.4. Пример: средний чек

```python
pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="mean",
    fill_value=0
)
```

---

## 10.5. Пример: количество продаж

```python
pd.pivot_table(
    df,
    values="sale_id",
    index="region_name",
    columns="category",
    aggfunc="count",
    fill_value=0
)
```

Если `sale_id` может повторяться, для количества уникальных продаж лучше:

```python
pd.pivot_table(
    df,
    values="sale_id",
    index="region_name",
    columns="category",
    aggfunc="nunique",
    fill_value=0
)
```

# 11. Параметр fill_value

## 11.1. Что такое fill_value

`fill_value` заменяет пустые значения в итоговой сводной таблице.

Если в Казани не было продаж одежды, без `fill_value` может быть `NaN`.

```python
pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum"
)
```

Результат может быть:

| region_name | мебель | одежда | электроника |
|---|---:|---:|---:|
| Казань | 30000 | NaN | 60000 |
| Москва | 50000 | 15000 | 120000 |

Если добавить:

```python
fill_value=0
```

получим:

| region_name | мебель | одежда | электроника |
|---|---:|---:|---:|
| Казань | 30000 | 0 | 60000 |
| Москва | 50000 | 15000 | 120000 |

---

## 11.2. Когда использовать fill_value=0

Используйте `fill_value=0`, если пустая ячейка означает:

> продаж по такой комбинации не было.

Например:

- нет продаж категории в регионе;
- нет заказов канала в месяце;
- нет количества товаров по сегменту.

Не используйте автоматически `0`, если пропуск может означать ошибку данных.

# 15. pivot_table и margins

Иногда нужно добавить итоги по строкам и столбцам.

```python
revenue_pivot_with_total = pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum",
    fill_value=0,
    margins=True,
    margins_name="Итого"
)

revenue_pivot_with_total
```

`margins=True` добавляет итоговые суммы.

Это удобно для отчета, но на первом знакомстве можно считать дополнительной темой.

# 16. Как проверить результат pivot_table

## 16.1. Проверить размер

```python
revenue_pivot.shape
```

## 16.2. Проверить строки

```python
revenue_pivot.index
```

## 16.3. Проверить столбцы

```python
revenue_pivot.columns
```

## 16.4. Проверить общую сумму

Если сводная таблица считает сумму выручки, можно сравнить:

```python
df["revenue"].sum()
revenue_pivot.sum().sum()
```

Если суммы совпадают, значит сводная таблица не потеряла выручку.

Важно: если в данных есть `NaN` в `index` или `columns`, результат может отличаться. В таком случае нужно отдельно проверить пропуски в группирующих столбцах.

# 17. Типовые ошибки начинающих

## Ошибка 1. Путают index и columns

Неправильно выбранные строки и столбцы не ломают код, но делают таблицу неудобной.

Если хотите видеть регионы строками:

```python
index="region_name"
```

Если хотите видеть категории столбцами:

```python
columns="category"
```

---

## Ошибка 2. Забыли values

Если не указать `values`, pandas может попытаться агрегировать все подходящие числовые столбцы.

Для начинающих лучше всегда явно писать:

```python
values="revenue"
```

---

## Ошибка 3. Неподходящий aggfunc

Например, для выручки чаще нужна сумма:

```python
aggfunc="sum"
```

А не среднее:

```python
aggfunc="mean"
```

Среднее тоже бывает полезно, но отвечает на другой вопрос.

---

## Ошибка 4. Столбец values не числовой

Если `revenue` загрузилась как текст, сумма может работать неправильно или вызвать ошибку.

Проверка:

```python
df["revenue"].dtype
```

Исправление:

```python
df["revenue"] = pd.to_numeric(df["revenue"], errors="coerce")
```

---

## Ошибка 5. Много NaN в сводной таблице

Причина: не для каждой комбинации строк и столбцов есть данные.

Решение:

```python
fill_value=0
```

Но только если 0 действительно означает отсутствие продаж.

---

## Ошибка 6. Сводная таблица получилась слишком широкой

Если в `columns` слишком много уникальных значений, таблица становится неудобной.

Например, не стоит делать:

```python
columns="product_name"
```

если товаров сотни.

Лучше использовать более крупный признак:

```python
columns="category"
```

---

## Ошибка 7. Сводная таблица получилась сложной из-за нескольких values

Если указать:

```python
values=["revenue", "gross_profit"]
```

pandas создаст многоуровневые столбцы.

Для начинающих лучше начать с одного показателя.

---

## Ошибка 8. Не проверили итоговую сумму

Если вы считаете сумму выручки, полезно проверить:

```python
df["revenue"].sum()
pivot.sum().sum()
```

Если суммы не совпадают, нужно выяснить почему.

---

## Ошибка 9. Используют pivot вместо pivot_table

`pivot()` не выполняет агрегацию и требует уникальные комбинации `index` и `columns`.

Если по одной комбинации есть несколько строк продаж, используйте:

```python
pd.pivot_table(...)
```

а не:

```python
df.pivot(...)
```

# 18. Сравнение groupby и pivot_table на одном вопросе

## Вопрос

> сколько выручки по регионам и категориям?

## Вариант groupby

```python
grouped = (
    df
    .groupby(["region_name", "category"], as_index=False)
    .agg(total_revenue=("revenue", "sum"))
)

grouped
```

Результат длинный:

| region_name | category | total_revenue |
|---|---|---:|
| Казань | мебель | 30000 |
| Казань | электроника | 60000 |
| Москва | одежда | 15000 |
| Москва | электроника | 120000 |

## Вариант pivot_table

```python
pivot = pd.pivot_table(
    df,
    values="revenue",
    index="region_name",
    columns="category",
    aggfunc="sum",
    fill_value=0
)

pivot
```

Результат широкий:

| region_name | мебель | одежда | электроника |
|---|---:|---:|---:|
| Казань | 30000 | 0 | 60000 |
| Москва | 0 | 15000 | 120000 |

## Как объяснить разницу

`groupby()` отвечает:

> какие итоги по группам?

`pivot_table()` отвечает:

> как эти итоги выглядят на пересечении строк и столбцов?

# 20. Как объяснить pivot_table за 1 минуту

> `pivot_table()` — это сводная таблица как в Excel.  
> Она нужна, когда мы хотим увидеть показатель на пересечении строк и столбцов.  
> Например, строки — регионы, столбцы — категории, значения внутри ячеек — сумма выручки.  
> `index` отвечает за строки, `columns` — за столбцы, `values` — за показатель, `aggfunc` — за способ расчета, `fill_value` — за замену пустых ячеек.  
> Если `groupby()` чаще дает длинную таблицу итогов, то `pivot_table()` делает широкую матрицу для сравнения.

# 23. Итог

`pivot_table()` нужна, когда аналитик хочет увидеть показатель на пересечении двух измерений.

Примеры:

```text
регион × категория
месяц × канал
тип клиента × категория
регион × канал
```

Главное правило:

> сначала сформулируйте вопрос, потом определите строки, столбцы, показатель и функцию расчета.

Схема:

```text
index   → что будет в строках
columns → что будет в столбцах
values  → что считаем
aggfunc → как считаем
fill_value → чем заменить пустые ячейки
```
