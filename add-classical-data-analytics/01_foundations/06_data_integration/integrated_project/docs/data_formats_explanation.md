# Раздатка: CSV, Excel, JSON и HTML-таблицы

## Тема

**Загрузка данных из разных форматов в pandas**

Эта раздатка предназначена для слушателей начального уровня.  
Цель — понять, чем отличаются основные форматы данных, где они встречаются, какие проблемы бывают при загрузке и какой командой pandas каждый формат читается.

---

# 1. Зачем аналитику знать разные форматы данных

В реальной работе аналитик редко получает одну идеальную таблицу.  
Чаще данные приходят из разных источников:

- отдел продаж выгружает CSV;
- коммерческий отдел ведет справочник товаров в Excel;
- внутренняя система или API отдает JSON;
- план продаж размещен на веб-странице в виде HTML-таблицы.

Задача аналитика — загрузить эти данные, проверить их качество и собрать в единую аналитическую таблицу.

В Python для этого часто используется библиотека `pandas`.

Стандартный импорт:

```python
import pandas as pd
```

# 2. Краткое сравнение форматов

| Формат | Что это простыми словами | Где встречается | Команда pandas |
|---|---|---|---|
| CSV | Текстовая таблица, где значения разделены запятыми, точками с запятой или другим разделителем | Выгрузки из CRM, 1С, маркетплейсов, банков, личных кабинетов | `pd.read_csv()` |
| Excel | Табличный файл с листами, форматированием и формулами | Ручные справочники, отчеты отделов, планы, управленческие таблицы | `pd.read_excel()` |
| JSON | Структурированный формат обмена данными, похожий на словари и списки | API, веб-сервисы, конфигурации, ответы внешних систем | `pd.read_json()` |
| HTML-таблица | Таблица внутри веб-страницы | Сайты, внутренние порталы, опубликованные таблицы | `pd.read_html()` |

# 3. CSV

## 3.1. Что такое CSV

**CSV** расшифровывается как **Comma-Separated Values** — значения, разделенные запятыми.

Но на практике разделителем может быть не только запятая:

```text
sale_id,product_id,quantity
1,101,2
2,102,5
```

Или точка с запятой:

```text
sale_id;product_id;quantity
1;101;2
2;102;5
```

CSV — это обычный текстовый файл. Его можно открыть в блокноте, VS Code, Excel, LibreOffice или другом редакторе.

## 3.2. Где встречается CSV

CSV часто встречается в аналитике, потому что это простой формат обмена таблицами.

Примеры:

- выгрузка продаж из CRM;
- отчет по заказам из маркетплейса;
- банковская выписка;
- выгрузка пользователей из сайта;
- результат работы скрипта;
- промежуточный файл между системами.

В нашем учебном кейсе CSV используется для файлов:

```text
sales.csv
clients.csv
```

## 3.3. Как pandas читает CSV

Базовая команда:

```python
sales = pd.read_csv("data/raw/sales.csv")
```

Если разделитель — точка с запятой:

```python
sales = pd.read_csv("data/raw/sales.csv", sep=";")
```

Если нужно указать кодировку:

```python
sales = pd.read_csv("data/raw/sales.csv", encoding="utf-8")
```

Для русскоязычных файлов иногда встречается:

```python
sales = pd.read_csv("data/raw/sales.csv", encoding="cp1251")
```

## 3.4. Частые проблемы при загрузке CSV

| Проблема | Как выглядит | Что делать |
|---|---|---|
| Неверный разделитель | Вся таблица загрузилась в один столбец | Указать `sep=";"`, `sep=","` или `sep="\t"` |
| Неверная кодировка | Ошибка `UnicodeDecodeError` или странные символы | Попробовать `encoding="utf-8"`, `encoding="utf-8-sig"`, `encoding="cp1251"` |
| Числа загрузились как текст | Нельзя корректно считать сумму или среднее | Использовать `pd.to_numeric()` |
| Даты загрузились как текст | Нельзя анализировать динамику | Использовать `pd.to_datetime()` |
| Лишние пробелы | `" online"` и `"online"` считаются разными значениями | Использовать `.str.strip()` |

## 3.5. Что проверить после загрузки CSV

```python
sales.head()
sales.shape
sales.info()
sales.isna().sum()
```

# 4. Excel

## 4.1. Что такое Excel-файл

Excel-файл — это табличный файл, обычно с расширением:

```text
.xlsx
```

В отличие от CSV, Excel может содержать:

- несколько листов;
- форматирование;
- формулы;
- объединенные ячейки;
- диаграммы;
- комментарии;
- несколько таблиц на одном листе.

Для человека Excel удобнее CSV, но для автоматической обработки он сложнее.

## 4.2. Где встречается Excel

Excel часто используют отделы бизнеса:

- коммерческий отдел ведет справочник товаров;
- финансовый отдел готовит план продаж;
- руководитель присылает отчет;
- менеджеры ведут ручные таблицы;
- отдел закупок хранит цены и поставщиков.

В нашем учебном кейсе Excel используется для файла:

```text
products.xlsx
```

## 4.3. Как pandas читает Excel

Базовая команда:

```python
products = pd.read_excel("data/raw/products.xlsx")
```

Если нужно прочитать конкретный лист:

```python
products = pd.read_excel(
    "data/raw/products.xlsx",
    sheet_name="products"
)
```

Посмотреть список листов:

```python
excel_file = pd.ExcelFile("data/raw/products.xlsx")
excel_file.sheet_names
```

## 4.4. Частые проблемы при загрузке Excel

| Проблема | Как выглядит | Что делать |
|---|---|---|
| Прочитан не тот лист | В таблице не те данные | Указать `sheet_name` |
| Заголовки не в первой строке | Названия столбцов стали `Unnamed` или числами | Использовать `header=...` |
| Лишние строки сверху | В таблицу попал заголовок отчета | Использовать `skiprows=...` |
| Несколько таблиц на одном листе | pandas загрузил лишние строки/столбцы | Ограничить диапазон или очистить файл |
| Формулы и форматирование | Видно одно, а читается другое | Проверить реальные значения после загрузки |
| Объединенные ячейки | Появляются пропуски | Проверить `isna().sum()` и структуру файла |

## 4.5. Что проверить после загрузки Excel

```python
products.head()
products.shape
products.info()
products.columns.tolist()
```

# 5. JSON

## 5.1. Что такое JSON

**JSON** — это формат обмена данными.  
Он часто используется в API и веб-сервисах.

JSON похож на сочетание словарей и списков.

Простой пример:

```json
[
  {
    "region_id": 1,
    "region_name": "Москва",
    "federal_district": "Центральный"
  },
  {
    "region_id": 2,
    "region_name": "Санкт-Петербург",
    "federal_district": "Северо-Западный"
  }
]
```

Для человека JSON менее похож на обычную таблицу, чем CSV или Excel.  
Но для программ и API это очень удобный формат.

## 5.2. Где встречается JSON

JSON часто встречается:

- в API;
- в ответах веб-сервисов;
- в конфигурационных файлах;
- в логах приложений;
- в данных мобильных приложений;
- в интеграциях между системами.

В нашем учебном кейсе JSON используется для файла:

```text
regions.json
```

## 5.3. Как pandas читает JSON

Базовая команда:

```python
regions = pd.read_json("data/raw/regions.json")
```

Проверка:

```python
regions.head()
regions.info()
```

## 5.4. Частые проблемы при загрузке JSON

| Проблема | Как выглядит | Что делать |
|---|---|---|
| JSON вложенный | В ячейках появляются списки или словари | Нужна нормализация, например `pd.json_normalize()` |
| Нестандартная структура | pandas не может сразу сделать таблицу | Сначала прочитать JSON как объект Python |
| Разные поля у разных записей | Появляются пропуски | Проверить `isna().sum()` |
| JSON не список объектов | Таблица получается не такой, как ожидали | Посмотреть структуру файла |
| Даты в виде текста | Даты не распознаны | Использовать `pd.to_datetime()` |

## 5.5. Что проверить после загрузки JSON

```python
regions.head()
regions.shape
regions.info()
regions.isna().sum()
```

# 6. HTML-таблица

## 6.1. Что такое HTML-таблица

HTML — это язык разметки веб-страниц.

На веб-странице может быть таблица:

```html
<table>
  <tr>
    <th>region_id</th>
    <th>channel</th>
    <th>sales_plan</th>
  </tr>
  <tr>
    <td>1</td>
    <td>online</td>
    <td>1000000</td>
  </tr>
</table>
```

pandas умеет находить таблицы на HTML-странице и превращать их в DataFrame.

## 6.2. Где встречаются HTML-таблицы

HTML-таблицы встречаются:

- на сайтах со статистикой;
- на внутренних корпоративных порталах;
- на страницах с тарифами;
- в опубликованных отчетах;
- в локально сохраненных HTML-файлах.

В нашем учебном кейсе HTML используется для файла:

```text
web_table_sample.html
```

## 6.3. Как pandas читает HTML-таблицу

Команда:

```python
tables = pd.read_html("data/raw/web_table_sample.html")
```

Важно: `read_html()` возвращает **список таблиц**, потому что на одной странице может быть несколько таблиц.

Взять первую таблицу:

```python
plans = tables[0]
```

Можно сразу:

```python
plans = pd.read_html("data/raw/web_table_sample.html")[0]
```

## 6.4. Частые проблемы при загрузке HTML

| Проблема | Как выглядит | Что делать |
|---|---|---|
| На странице несколько таблиц | Загружена не та таблица | Посмотреть `len(tables)` и проверить каждую |
| Таблица сложная | Многоуровневые заголовки или лишние строки | Очистить DataFrame после загрузки |
| Страница требует интернет | В аудитории без Wi‑Fi не работает | Использовать локальный HTML-файл |
| Таблица формируется JavaScript | `read_html()` не видит таблицу | Нужен другой способ сбора данных |
| Нет парсера HTML | Ошибка импорта | Проверить установку зависимостей |

## 6.5. Что проверить после загрузки HTML

```python
tables = pd.read_html("data/raw/web_table_sample.html")

len(tables)
tables[0].head()
tables[0].info()
```

# 7. Главное различие форматов

## CSV

Лучше всего подходит для простого обмена одной таблицей.

```python
pd.read_csv("file.csv")
```

## Excel

Удобен для людей, ручного просмотра и нескольких листов.

```python
pd.read_excel("file.xlsx", sheet_name="sheet1")
```

## JSON

Часто используется системами и API.

```python
pd.read_json("file.json")
```

## HTML-таблица

Используется для таблиц на веб-страницах или в локальных HTML-файлах.

```python
pd.read_html("file.html")[0]
```

# 8. Общая схема работы аналитика после загрузки любого формата

После загрузки любого файла выполняйте один и тот же набор проверок:

```python
df.head()
df.shape
df.columns.tolist()
df.info()
df.isna().sum()
df.duplicated().sum()
```

Если в таблице есть даты:

```python
df["date_column"] = pd.to_datetime(df["date_column"], errors="coerce")
```

Если в таблице есть числа, которые загрузились как текст:

```python
df["numeric_column"] = pd.to_numeric(df["numeric_column"], errors="coerce")
```

Если в таблице есть текстовые категории:

```python
df["text_column"] = (
    df["text_column"]
    .astype("string")
    .str.strip()
    .str.lower()
)
```

# 10. Как объяснить это совсем коротко

Если нужно объяснить за 1 минуту:

> CSV — простая текстовая таблица.  
> Excel — таблица для людей, может иметь листы и форматирование.  
> JSON — формат обмена данными между системами и API.  
> HTML-таблица — таблица внутри веб-страницы.  
> pandas умеет читать все эти форматы, но после загрузки всегда нужно проверять структуру, типы, пропуски и дубликаты.

# 11. Практический пример для занятия

```python
import pandas as pd

sales = pd.read_csv("data/raw/sales.csv")
products = pd.read_excel("data/raw/products.xlsx", sheet_name="products")
regions = pd.read_json("data/raw/regions.json")
clients = pd.read_csv("data/raw/clients.csv")
plans = pd.read_html("data/raw/web_table_sample.html")[0]

for name, df in {
    "sales": sales,
    "products": products,
    "regions": regions,
    "clients": clients,
    "plans": plans,
}.items():
    print(name, df.shape)
    display(df.head())
```

# 13. Типовые ошибки и быстрые решения

| Ошибка | Вероятная причина | Быстрое решение |
|---|---|---|
| `FileNotFoundError` | Неверный путь к файлу | Проверить `Path.cwd()` и путь |
| `UnicodeDecodeError` | Неверная кодировка CSV | Попробовать `utf-8-sig` или `cp1251` |
| CSV загрузился одной колонкой | Неверный разделитель | Указать `sep=";"` или другой разделитель |
| `ValueError` при расчетах | Число загрузилось как текст | Использовать `pd.to_numeric()` |
| Даты не работают | Дата загрузилась как текст | Использовать `pd.to_datetime()` |
| В HTML загружена не та таблица | На странице несколько таблиц | Проверить `len(tables)` и выбрать нужный индекс |
| В Excel не тот лист | Не указан `sheet_name` | Посмотреть `ExcelFile(...).sheet_names` |
| Много `NaN` после загрузки | Разная структура строк или пустые поля | Проверить исходный файл и `df.info()` |
