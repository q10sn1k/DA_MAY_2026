# Учебный блок: как выбрать тип графика для аналитической задачи

## Тема

**Базовая визуализация продаж: line chart, bar chart, histogram, boxplot, scatter plot**

Цель блока — научиться выбирать график не «по красоте», а по аналитическому вопросу.

Главное правило:

> Сначала формулируем вопрос, потом выбираем график.

---

# 1. Быстрая таблица выбора графика

| Аналитический вопрос | Что хотим увидеть | Подходящий график |
|---|---|---|
| Как менялась выручка по датам? | Динамику во времени | Line chart |
| Какая категория продается лучше? | Сравнение категорий | Bar chart |
| Какие регионы в топе по выручке? | Рейтинг категорий или регионов | Bar chart / horizontal bar chart |
| Как распределены суммы заказов? | Частоту разных значений | Histogram |
| Есть ли выбросы по сумме заказа? | Разброс и аномально большие/маленькие значения | Boxplot |
| Есть ли связь между ценой и количеством? | Связь двух числовых показателей | Scatter plot |

---

# 2. Line chart: линейный график

## Когда использовать

Line chart используем, когда нужно показать **изменение показателя во времени**.

Подходит для вопросов:

- как менялась выручка по дням;
- есть ли рост или падение продаж;
- в какие даты были пики;
- как менялась прибыль по месяцам.

## Пример вопроса

> Как менялась выручка компании по датам?

## Пример подготовки данных

```python
daily_revenue = (
    df
    .groupby("order_date", as_index=False)
    .agg(total_revenue=("revenue", "sum"))
    .sort_values("order_date")
)
```

## Пример графика

```python
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 5))
plt.plot(daily_revenue["order_date"], daily_revenue["total_revenue"], marker="o")
plt.title("Динамика выручки по датам")
plt.xlabel("Дата")
plt.ylabel("Выручка")
plt.xticks(rotation=45)
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Как объяснить слушателям

> Линейный график хорош, когда по оси X идет время: дата, неделя, месяц, квартал. Он показывает направление изменения: растет показатель, падает или колеблется.

## Частая ошибка

Использовать line chart для категорий, где нет естественного порядка.

Плохо:

```text
категория A → категория B → категория C
```

Если категории не являются временем, лучше использовать bar chart.

---

# 3. Bar chart: столбчатая диаграмма

## Когда использовать

Bar chart используем, когда нужно **сравнить категории между собой**.

Подходит для вопросов:

- какая категория дает больше выручки;
- какой регион лидирует;
- какой канал продаж приносит больше заказов;
- какие товары входят в топ продаж.

## Пример вопроса

> Какие категории дают наибольшую выручку?

## Пример подготовки данных

```python
category_revenue = (
    df
    .groupby("category", as_index=False)
    .agg(total_revenue=("revenue", "sum"))
    .sort_values("total_revenue", ascending=False)
)
```

## Пример графика

```python
plt.figure(figsize=(10, 5))
plt.bar(category_revenue["category"], category_revenue["total_revenue"])
plt.title("Выручка по категориям")
plt.xlabel("Категория")
plt.ylabel("Выручка")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

## Когда лучше использовать горизонтальный bar chart

Если названия категорий длинные или регионов много, удобнее горизонтальная диаграмма:

```python
top_regions = (
    df
    .groupby("region_name", as_index=False)
    .agg(total_revenue=("revenue", "sum"))
    .sort_values("total_revenue", ascending=False)
    .head(10)
)

top_regions_for_plot = top_regions.sort_values("total_revenue")

plt.figure(figsize=(10, 6))
plt.barh(top_regions_for_plot["region_name"], top_regions_for_plot["total_revenue"])
plt.title("Топ-10 регионов по выручке")
plt.xlabel("Выручка")
plt.ylabel("Регион")
plt.tight_layout()
plt.show()
```

## Как объяснить слушателям

> Столбчатая диаграмма нужна, когда мы сравниваем группы: категории, регионы, каналы, товары. Чем выше или длиннее столбец, тем больше значение.

## Частая ошибка

Строить bar chart по слишком большому количеству категорий.

Если категорий слишком много:

- взять топ-10;
- использовать горизонтальный график;
- сгруппировать мелкие категории в «прочее».

---

# 4. Histogram: гистограмма

## Когда использовать

Histogram используем, когда нужно показать **распределение числового показателя**.

Подходит для вопросов:

- какие суммы заказов встречаются чаще всего;
- много ли маленьких заказов;
- есть ли редкие очень крупные заказы;
- как распределяется скидка;
- как распределяется количество товаров в заказе.

## Пример вопроса

> Как распределены суммы заказов?

## Пример графика

```python
plt.figure(figsize=(10, 5))
plt.hist(df["revenue"].dropna(), bins=15)
plt.title("Распределение суммы заказа")
plt.xlabel("Сумма заказа")
plt.ylabel("Количество заказов")
plt.tight_layout()
plt.show()
```

## Как объяснить слушателям

> Гистограмма не сравнивает категории. Она показывает, как часто встречаются разные диапазоны числового значения. Например, сколько заказов попали в диапазон 0–5 000, 5 000–10 000 и так далее.

## Частая ошибка

Путать histogram и bar chart.

| График | Для чего |
|---|---|
| Bar chart | сравнить категории |
| Histogram | посмотреть распределение числового показателя |

---

# 5. Boxplot: ящик с усами

## Когда использовать

Boxplot используем, когда нужно увидеть:

- разброс значений;
- медиану;
- типичный диапазон;
- выбросы;
- различия распределений между группами.

Подходит для вопросов:

- есть ли выбросы в суммах заказов;
- в какой категории заказы более дорогие;
- где разброс чеков выше;
- какие категории имеют аномально крупные заказы.

## Пример вопроса

> В каких категориях есть выбросы по сумме заказа?

## Пример подготовки данных

```python
boxplot_data = []
boxplot_labels = []

for category, group in df.groupby("category"):
    values = group["revenue"].dropna()
    if not values.empty:
        boxplot_data.append(values)
        boxplot_labels.append(str(category))
```

## Пример графика

```python
plt.figure(figsize=(10, 5))
plt.boxplot(boxplot_data, labels=boxplot_labels)
plt.title("Распределение суммы заказа по категориям")
plt.xlabel("Категория")
plt.ylabel("Сумма заказа")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

## Как объяснить слушателям

> Boxplot показывает не отдельные продажи, а распределение: где находится середина значений, насколько велик разброс и есть ли необычно большие или маленькие значения.

## Частая ошибка

Считать любой выброс ошибкой.

Выброс — это не всегда ошибка.  
Например, крупный корпоративный заказ может быть реальной продажей, а не проблемой данных.

---

# 6. Scatter plot: диаграмма рассеяния

## Когда использовать

Scatter plot используем, когда нужно посмотреть **связь между двумя числовыми показателями**.

Подходит для вопросов:

- есть ли связь между ценой и количеством;
- связаны ли выручка и прибыль;
- больше ли скидка у крупных заказов;
- как цена влияет на количество проданных товаров.

## Пример вопроса

> Есть ли связь между выручкой и валовой прибылью?

## Пример графика

```python
plt.figure(figsize=(8, 5))
plt.scatter(df["revenue"], df["gross_profit"])
plt.title("Связь выручки и валовой прибыли")
plt.xlabel("Выручка")
plt.ylabel("Валовая прибыль")
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Еще пример

```python
plt.figure(figsize=(8, 5))
plt.scatter(df["unit_price"], df["quantity"])
plt.title("Связь цены и количества")
plt.xlabel("Цена за единицу")
plt.ylabel("Количество")
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Как объяснить слушателям

> Каждая точка — это одна продажа или один заказ. Если точки образуют заметное направление, возможно, между показателями есть связь. Но график сам по себе не доказывает причинно-следственную связь.

## Частая ошибка

Делать вывод «одно вызывает другое» только по scatter plot.

Правильнее сказать:

> на графике видна связь или закономерность, которую нужно дополнительно проверить.

---

# 7. Общая логика выбора графика

Перед построением графика задайте себе 4 вопроса:

## Вопрос 1. Есть ли время?

Если да, часто нужен line chart.

Пример:

```text
дата заказа → выручка
```

## Вопрос 2. Нужно сравнить группы?

Если да, нужен bar chart.

Пример:

```text
категория → выручка
регион → прибыль
канал → количество заказов
```

## Вопрос 3. Нужно посмотреть распределение одного числового показателя?

Если да, нужен histogram.

Пример:

```text
revenue
discount_percent
quantity
```

## Вопрос 4. Нужно сравнить разброс и выбросы по группам?

Если да, нужен boxplot.

Пример:

```text
revenue по категориям
revenue по каналам
```

## Вопрос 5. Нужно увидеть связь двух числовых показателей?

Если да, нужен scatter plot.

Пример:

```text
revenue и gross_profit
unit_price и quantity
discount_percent и revenue
```

| График | Когда использовать | Пример по продажам |
|---|---|---|
| Line chart | Динамика во времени | выручка по датам |

# 9. Типовые ошибки начинающих

## Ошибка 1. График строится без вопроса

Плохо:

> Давайте просто построим график.

Хорошо:

> Нужно понять, какие категории дают больше выручки. Для этого подойдет bar chart.

---

## Ошибка 2. Line chart используют для категорий

Если по оси X категории без порядка, лучше использовать bar chart.

---

## Ошибка 3. Bar chart строят по сотням товаров

Если категорий слишком много, график станет нечитаемым.

Решение:

```python
.head(10)
```

или группировка мелких категорий.

---

## Ошибка 4. Histogram используют для категорий

Гистограмма нужна для числового распределения, а не для категорий.

---

## Ошибка 5. Не подписывают оси

Каждый график должен иметь:

```python
plt.title(...)
plt.xlabel(...)
plt.ylabel(...)
```

---

## Ошибка 6. Подписи налезают друг на друга

Решения:

```python
plt.xticks(rotation=45)
plt.tight_layout()
```

или горизонтальный bar chart.

---

## Ошибка 7. Делают вывод по графику без проверки данных

Перед графиком нужно проверить:

```python
df.shape
df.info()
df.isna().sum()
```

Если данные грязные, график может быть красивым, но неверным.

---

# 10. Как объяснить тему за 1 минуту

> Тип графика выбирается по аналитической задаче.  
> Если мы смотрим изменение во времени — используем line chart.  
> Если сравниваем категории, регионы или каналы — bar chart.  
> Если хотим понять распределение сумм заказов — histogram.  
> Если ищем разброс и выбросы — boxplot.  
> Если проверяем связь двух числовых показателей, например выручки и прибыли, — scatter plot.  
> Главное: график должен отвечать на конкретный вопрос, а не просто украшать отчет.

# 12. Итог

График должен помогать ответить на вопрос.

Схема выбора:

```text
динамика → line chart
сравнение групп → bar chart
распределение → histogram
выбросы и разброс → boxplot
связь двух чисел → scatter plot
```

Если вы не можете объяснить, на какой вопрос отвечает график, значит тип графика выбран неудачно.
