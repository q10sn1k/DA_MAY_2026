# Подготовка к занятию без Wi‑Fi

## За 1–2 дня до занятия

1. Установите Python 3.11+ (или используйте уже рабочую среду Anaconda/Miniconda).
2. Скопируйте весь каталог занятия на локальный диск.
3. В терминале из корня каталога выполните:

```bash
python -m pip install -r requirements.txt
python env_check.py
```

4. Убедитесь, что Jupyter или VS Code открывает `.ipynb`.
5. Не рассчитывайте на загрузку библиотек, датасетов или документации из интернета в аудитории.

## Резервный маршрут преподавателя

Если у части группы не запускается Python:

- объединить слушателей в пары;
- использовать преподавательские PNG из `teacher/out/`;
- сохранить аналитическую часть задания: выбор типа графика, чтение осей, интерпретацию, поиск ошибок и формулировку выводов.

## Минимальная проверка

```bash
python env_check.py
```

Скрипт проверяет версии библиотек и наличие подготовленного датасета.
