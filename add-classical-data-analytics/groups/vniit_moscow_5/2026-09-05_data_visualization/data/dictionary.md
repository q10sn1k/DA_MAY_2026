# Словарь данных — «РегионМаркет»

| Поле | Тип | Смысл |
|---|---|---|
| `order_id` | string | идентификатор заказа |
| `order_date` | date | дата заказа |
| `region` | string | регион продажи |
| `channel` | string | канал: Онлайн / Магазин / Партнеры |
| `customer_type` | string | Новый / Повторный / Корпоративный |
| `category` | string | категория товара |
| `subcategory` | string | подкатегория |
| `quantity` | int | количество единиц в заказе |
| `unit_price` | float | цена единицы после сезонной корректировки учебного генератора |
| `discount_percent` | int | скидка, % |
| `revenue` | float | выручка заказа |
| `cost` | float | учебная оценка себестоимости и логистики |
| `profit` | float | `revenue - cost` |
| `profit_margin` | float | `profit / revenue` |
| `delivery_days` | int | срок доставки, дней |
| `rating` | float | оценка клиента от 1 до 5 |

## Гранулярность

Одна строка = один заказ.

## Важно

Данные синтетические. Корреляции и закономерности внутри них созданы только для учебной практики и не являются фактами о реальном рынке.
