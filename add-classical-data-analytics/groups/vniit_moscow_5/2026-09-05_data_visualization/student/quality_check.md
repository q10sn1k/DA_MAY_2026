# Чек-лист качества визуализации

Перед сдачей каждого графика проверьте:

- [ ] график отвечает на конкретный аналитический вопрос;
- [ ] данные для графика подготовлены на правильной гранулярности;
- [ ] заголовок описывает содержание, а не тип графика;
- [ ] ось X подписана;
- [ ] ось Y подписана и содержит единицы измерения;
- [ ] даты и числовые деления читаются;
- [ ] для динамики есть достаточно major/minor ticks, чтобы понимать временную привязку точек;
- [ ] для столбчатых графиков нет манипулятивно обрезанной шкалы;
- [ ] категории отсортированы, если порядок несет смысл;
- [ ] легенда нужна и не дублирует очевидное;
- [ ] нет 3D-декора, который искажает сравнение;
- [ ] количество визуальных элементов не мешает чтению;
- [ ] выбросы проверены, но не удалены автоматически;
- [ ] корреляция не названа причинностью;
- [ ] под графиком сформулирован содержательный аналитический вывод;
- [ ] PNG/другой экспорт создан, если он нужен для отчета.

## Формула хорошего вывода

**Наблюдение → показатель/доказательство → интерпретация → ограничение/следующий шаг.**
