# Windows: короткие пути

Комплект использует сокращенные имена каталогов и файлов, чтобы снизить риск ошибки `0x80010135: Слишком длинный путь`.

Рекомендуемый вариант:

```text
C:\DA\DA_MAY_2026\groups\VNIIT_MSK5\2026-09-05_viz\
```

Если локальный репозиторий уже находится глубоко в профиле пользователя или облачной синхронизируемой папке, переместите/клонируйте его ближе к корню диска. Включение long paths в Windows может помочь отдельным приложениям, но не все приложения обязаны использовать этот режим.
