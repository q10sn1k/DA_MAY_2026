## Принятое методическое решение

Практическая часть занятия выполняется на **Python**. Отдельного R-каталога, R-ноутбука и установки R для занятия нет. Требование программы по упоминанию R закрывается коротким обзорным блоком преподавателя без практики: что такое R/ggplot2, где такой стек встречается и почему основной hands-on занятия выполняется на Python.

Основной стек:

- `pandas` — подготовка данных к визуализации;
- `Matplotlib` — базовая и настраиваемая визуализация;
- `Seaborn` — статистическая визуализация и EDA;
- Jupyter Notebook / VS Code — среда выполнения.

## Главный учебный результат

После занятия слушатель должен уметь пройти цепочку:

> аналитический вопрос → выбор графика → подготовка данных → построение → оформление → интерпретация → проверка качества → экспорт результата.

Итоговое наблюдаемое подтверждение результата — самостоятельный мини-кейс с не менее чем пятью корректными визуализациями и выводами, связанными с данными.

## С чего начать слушателю

1. До занятия выполнить `python env_check.py`.
2. Открыть `student/nb/01_basics.ipynb`.
3. Выполнять ноутбуки по порядку `01 → 02 → 03 → 04`.
4. Итоговые графики сохранять в `outputs/`.
5. Во время занятия и после него использовать `student/notes.docx` как основной конспект-справочник.
6. Для финальной самопроверки использовать `student/quality_check.md`.

## Dataset

Используется **синтетический учебный кейс «РегионМаркет»**, созданный специально для занятия. Это не реальные коммерческие или персональные данные.

Подготовленный датасет содержит 1200 заказов за период 2026-01-01 — 2026-06-30 и позволяет отработать:

- временную динамику;
- сравнение категорий и регионов;
- распределения и выбросы;
- связь двух количественных признаков;
- сегментацию по каналу и типу клиента;
- интерпретацию связи сроков доставки с оценкой клиента.

`data/raw.csv` содержит контролируемые учебные проблемы качества. Основная практика выполняется на `data/viz.csv`.

## Windows: короткие пути

Эта версия комплекта использует сокращенную структуру путей. Рекомендуется распаковывать архив непосредственно в корень локального клона репозитория или в короткий временный путь, например `C:\DA\`. Не добавляйте лишние уровни каталогов вокруг комплекта.

## Offline-first

В расписании группы указано отсутствие Wi‑Fi в аудитории, поэтому занятие не требует сетевых API, SaaS-инструментов или загрузки датасетов во время занятия. Все необходимые данные находятся в этом каталоге. Подготовку библиотек нужно выполнить заранее.

## Проверка сборки

Преподавательские ноутбуки должны запускаться сверху вниз на чистом ядре. В `teacher/out/` сохраняются эталонные PNG-графики; контрольные метрики находятся в `teacher/metrics.md`.
