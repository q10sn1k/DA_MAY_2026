# Финальный чек-лист работы в DataLens

## Подключение

- [ ] создан собственный воркбук;
- [ ] загружены основные CSV;
- [ ] разделитель и кодировка распознаны корректно;
- [ ] подключение сохранено.

## Связи

- [ ] `support_tickets` используется как левая таблица фактов;
- [ ] `customers` связан по `customer_id`;
- [ ] `regions` связан по `region_id`;
- [ ] выбран `LEFT JOIN`;
- [ ] типы ключей совпадают;
- [ ] 1510 записей и 1500 уникальных обращений;
- [ ] 28 уникальных обращений имеют неизвестный регион;
- [ ] строки не размножились после JOIN.

## Основной датасет

- [ ] одна строка соответствует одному обращению;
- [ ] 1500 уникальных `ticket_id`;
- [ ] даты имеют тип «Дата»;
- [ ] числовые поля распознаны как числа;
- [ ] созданы четыре общих KPI;
- [ ] доля SLA имеет процентный формат.

## Чарты

- [ ] четыре KPI;
- [ ] динамика по дням;
- [ ] оценка по каналам;
- [ ] время решения по категориям;
- [ ] точечный график времени решения и оценки;
- [ ] у каждого чарта понятный заголовок и единицы измерения.

## Дашборд

- [ ] есть вкладка «Операционный обзор»;
- [ ] есть селекторы периода, региона и канала;
- [ ] селекторы меняют нужные чарты;
- [ ] сброс фильтров возвращает контрольные KPI;
- [ ] есть вкладка «Лаборатория гипотез»;
- [ ] визуальный вывод отделён от статистического вывода.

## Безопасность и передача

- [ ] публичный доступ не включён;
- [ ] в данных нет персональной информации;
- [ ] ссылка передаётся только в согласованном контуре;
