# Вычисляемые поля DataLens

Функции могут зависеть от типа подключения. Формулы ниже соответствуют актуальному синтаксису DataLens; перед публикацией проверьте доступность функций для конкретного источника.

## Геоточка региона

```text
GEOPOINT([latitude], [longitude])
```

Тип результата: `Geopoint`. Используется в секции `Точки` карты.

## Доля нарушений SLA

```text
SUM([sla_breached]) / SUM([tickets_count])
```

Формат: проценты, 2 знака. Не используйте `AVG` от заранее рассчитанных процентов.

## Средняя вероятность риска

```text
AVG([risk_probability])
```

Формат: проценты, 1–2 знака.

## Высокорисковые обращения

```text
SUM([risk_class])
```

## Признак дефицита мощности

```text
IF([capacity_gap] > 0, 1, 0)
```

## Дни дефицита

```text
COUNTD_IF([date], [capacity_gap] > 0)
```

Если функция недоступна для выбранного источника, заранее добавьте в CSV бинарное поле `has_capacity_gap` и агрегируйте `SUM([has_capacity_gap])`.

## Критические нарушения качества

```text
COUNT_IF([severity] = 'critical' AND [status] = 'FAIL')
```

## Цветовая категория риска

```text
CASE
  WHEN [risk_probability] >= 0.70 THEN 'Высокий'
  WHEN [risk_probability] >= 0.40 THEN 'Средний'
  ELSE 'Низкий'
END
```

Эти границы предназначены только для визуальной группировки. Рабочий класс `risk_class` должен рассчитываться по порогу, выбранному в notebook `04b`.
