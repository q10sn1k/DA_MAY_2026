# Описание учебных данных

## Назначение

Набор данных моделирует обращения клиентов в службу поддержки. Он предназначен для практики анализа взаимосвязей, проверки статистических гипотез и анализа временных рядов.

Данные синтетические. Они не содержат реальных персональных данных, адресов, телефонов, email, паролей, токенов или рабочих доступов.

## Связи между таблицами

```text
support_tickets.customer_id -> customers.customer_id
support_tickets.region_id   -> regions.region_id
```

## support_tickets.csv

| Поле | Ожидаемый тип после загрузки | Назначение | Пример | Контролируемые проблемы |
|---|---|---|---|---|
| `ticket_id` | string | Идентификатор обращения | `TCK-000123` | 10 повторных идентификаторов |
| `created_at` | datetime | Дата и время создания | `2026-05-14 10:35:00` | В CSV хранится строкой |
| `customer_id` | string | Идентификатор клиента | `CUST-0042` | Нет |
| `region_id` | string | Идентификатор региона | `R03` | Пропуски и `R99` |
| `channel` | category/string | Канал обращения | `chat` | Пробелы и разный регистр |
| `category` | category/string | Категория проблемы | `technical` | Пробелы и разный регистр |
| `priority` | category/string | Приоритет | `normal` | Нет |
| `first_response_min` | float | Минуты до первого ответа | `18.5` | Несколько значений <= 0 |
| `resolution_hours` | float | Часы до решения | `12.4` | Контролируемые выбросы > 140 часов |
| `sla_breached` | int/bool | Нарушение SLA | `1` | Нет |
| `satisfaction_score` | float | Оценка клиента 1–5 | `4.2` | Пропуски |

## Допустимые очищенные категории

- `channel`: `chat`, `email`, `phone`, `web_form`;
- `category`: `login`, `payment`, `delivery`, `account`, `technical`, `refund`;
- `priority`: `low`, `normal`, `high`, `critical`;
- `segment`: `b2c`, `b2b`, `vip`.

## Учебные закономерности

После очистки данных должны проявляться следующие эффекты:

1. Чем больше время решения, тем ниже оценка клиента.
2. Средняя оценка в `chat` выше средней оценки в `email`.
3. Обращения с приоритетом `high` в среднем решаются дольше, чем `normal`.
4. При нарушении SLA средняя оценка ниже.
5. В будни среднее число обращений выше, чем в выходные.
6. Во второй половине периода средняя дневная нагрузка выше, чем в первой.
