# Преобразование данных в R: нормализация, стандартизация и аналитическая витрина

## Назначение

Этот материал поддерживает четвертый 90-минутный комплект практического семинара. Слушатели повторяют в R ту же производственную задачу, которую ранее выполняли в Python: подготовить данные продаж к аналитическому отчету.

Главная идея блока: R изучается не как отдельный набор команд, а как инструмент для уже знакомого аналитического процесса.

## Рабочая цепочка

1. Проверить структуру проекта и наличие файлов.
2. Загрузить CSV, XLSX и JSON.
3. Очистить текстовые поля и ключи.
4. Нормализовать каналы продаж, категории и сегменты.
5. Преобразовать даты и числовые поля.
6. Поставить флаги качества.
7. Исключить строки с критичными ошибками.
8. Объединить фактовую таблицу со справочниками.
9. Рассчитать выручку, маржу, z-score и min-max нормализацию.
10. Сформировать сводку по регионам и каналам.
11. Сохранить результат и сформулировать аналитическое решение.

## Основные функции R

| Функция | Пакет | Зачем используется |
|---|---|---|
| `read_csv()` | readr | чтение CSV-файлов |
| `read_excel()` | readxl | чтение Excel-справочника |
| `fromJSON()` | jsonlite | чтение JSON-справочника |
| `mutate()` | dplyr | создание и изменение столбцов |
| `filter()` | dplyr | отбор строк |
| `distinct()` | dplyr | удаление дублей справочников по ключу |
| `left_join()` | dplyr | присоединение справочников к продажам |
| `group_by()` | dplyr | группировка перед расчетом показателей |
| `summarise()` | dplyr | расчет агрегированных показателей |
| `str_trim()` | stringr | удаление лишних пробелов |
| `str_to_lower()` / `str_to_upper()` | stringr | приведение текста к единому регистру |
| `ymd()` | lubridate | преобразование дат формата YYYY-MM-DD |
| `write_csv()` | readr | сохранение результатов |
