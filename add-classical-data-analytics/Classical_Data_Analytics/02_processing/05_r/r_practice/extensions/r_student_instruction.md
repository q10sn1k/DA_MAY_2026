# Инструкция для слушателей: первый запуск R на аналитическом кейсе

## Цель

Запустить RStudio, открыть проект, проверить исходные файлы и выполнить первые проверки данных по знакомому кейсу продаж.

## Что понадобится

- установленный R;
- установленный RStudio Desktop;
- распакованный архив с учебным проектом;
- файлы в папке `data/raw`.

## Порядок выполнения

1. Откройте файл `data_quality_audit_case_v1.Rproj`.
2. Откройте файл `r/03_setup_packages.R`.
3. Запустите его целиком.
4. Откройте файл `r/03_r_check_environment.R`.
5. Запустите его и проверьте, что все исходные файлы найдены.
6. Откройте файл `r/03_r_first_steps_student.R`.
7. Выполните скрипт сверху вниз.
8. Проверьте папку `outputs`.
9. Откройте созданные CSV-файлы и посмотрите результаты проверок.
10. Прочитайте файл `outputs/r_first_decision.md` и при необходимости дополните его своими наблюдениями.

## Что должно получиться

```text
outputs/r_environment_check.csv
outputs/r_loaded_data_summary.csv
outputs/r_first_quality_preview.csv
outputs/r_reference_preview.csv
outputs/r_first_decision.md
```

## Самопроверка

- RStudio открыт.
- Проект открыт через `.Rproj`.
- `getwd()` показывает корневую папку проекта.
- Все исходные файлы найдены.
- Пакеты `tidyverse`, `readxl`, `jsonlite` подключены.
- Таблицы `sales`, `products`, `clients`, `regions` созданы.
- Результаты сохранены в `outputs`.
- Вы можете объяснить, какие проблемы качества обнаружены в R.
