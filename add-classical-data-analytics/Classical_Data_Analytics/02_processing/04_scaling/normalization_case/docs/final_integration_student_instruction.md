# Финальная сверка Python- и R-результатов

## Цель

Проверить, совпадают ли результаты обработки данных, полученные в Python и R, и подготовить короткий итоговый вывод аналитика.

## Исходная ситуация

Вы подготовили аналитическую витрину по продажам в Python и повторили основные преобразования в R. Перед тем как использовать результат в отчёте, нужно убедиться, что оба инструмента дают одинаковые контрольные показатели.

## Что получится в результате

После выполнения работы в папке `outputs` должны быть файлы:

```text
final_python_r_comparison.csv
final_report_differences.csv
final_integrated_report.md
```

## Что нужно сравнить

| Python-файл | R-файл | Что проверяется |
|---|---|---|
| `sales_datamart.csv` | `r_expected_sales_datamart.csv` | строки витрины, выручка, маржа, каналы, категории |
| `report_by_region_channel.csv` | `r_expected_report_by_region_channel.csv` | региональная сводка по каналам |

## Порядок выполнения

1. Откройте notebook `notebooks/05_compare_python_r_results.ipynb`.
2. Запустите блок проверки файлов.
3. Загрузите Python- и R-результаты.
4. Отсортируйте таблицы по ключам.
5. Сравните количество строк и столбцов.
6. Сравните итоговую выручку и маржу.
7. Сравните состав каналов и категорий.
8. Сравните сводку по регионам и каналам.
9. Сохраните таблицу сверки.
10. Заполните итоговый вывод аналитика.

## Самопроверка

Проверьте:

- все нужные файлы найдены;
- notebook запускается сверху вниз;
- итоговая выручка совпадает;
- итоговая маржа совпадает;
- количество строк витрины совпадает;
- количество строк региональной сводки совпадает;
- в файле расхождений нет критичных отличий;
- итоговый вывод написан своими словами.

## Что показать преподавателю
