# Промтинг в аналитике данных

Комплект для 90-минутного вебинара о применении промтинга в работе аналитика данных.

## Состав

- `presentation/prompting_data_analytics_webinar.pptx` — презентация на 18 слайдов со speaker notes.
- `data/sales_sample.csv` — синтетический учебный датасет продаж.
- `materials/data_dictionary.md` — описание полей датасета.
- `materials/prompt_constructor.md` — шаблон рабочего промта аналитика.
- `materials/validation_checklist.md` — чек-лист проверки промта и ответа модели.
- `materials/security_checklist.md` — правила безопасной работы с данными и внешним контентом.


## Полный суфлёр преподавателя

В папке `teacher/` находятся материалы для проведения вебинара вживую:

- `teacher_teleprompter_full.docx` — оформленный полный суфлёр на 34 страницы;
- `teacher_teleprompter_full.pdf` — версия для чтения и печати;
- `teacher_teleprompter_full.md` — редактируемая текстовая версия;
- `teacher_timing_card.md` — краткая карточка тайминга на 90 минут.

Суфлёр привязан к 18 слайдам и содержит точный текст речи, действия на экране, вопросы аудитории, демонстрационные промты, контрольные значения, переходы и резервные сценарии.

## Учебный кейс

Руководитель предполагает, что увеличение скидок повысило выручку. Слушатели должны сформулировать промт для проверки гипотезы, получить ответ модели, найти в нём недостаток и улучшить промт.

## Безопасность данных

Датасет полностью синтетический и не содержит персональных данных, токенов, паролей или рабочих доступов.

## Контролируемые проблемы качества

В данных намеренно заложены учебные проблемы: дубликаты заказов, пропуски, некорректная дата, разные варианты написания категорий, отрицательные и нулевые значения, аномальная скидка.


## Эталонный notebook преподавателя

Файл: `notebooks/prompting_practice_teacher.ipynb`

Notebook:

- запускается сверху вниз;
- использует относительные пути;
- проверяет качество исходного CSV;
- формирует очищенную аналитическую витрину;
- рассчитывает месячные и сегментные KPI;
- разбирает гипотезу о скидках и выручке;
- сохраняет таблицы и графики в `outputs/`;
- содержит демонстрационные промты и методические комментарии.

### Запуск

```bash
pip install -r requirements.txt
jupyter notebook notebooks/prompting_practice_teacher.ipynb
```


## Notebook слушателя

Файл: `notebooks/prompting_practice_student.ipynb`

Notebook:

- запускается сверху вниз;
- использует относительные пути;
- содержит управляемую практику для начинающих;
- не содержит эталонных аналитических выводов;
- помогает создать и улучшить собственный промт;
- включает проверку данных, кода и интерпретации;
- сохраняет портфолио в `outputs/prompt_portfolio.md`.

### Запуск

```bash
pip install -r requirements.txt
jupyter notebook notebooks/prompting_practice_student.ipynb
```

## Контроль и самостоятельная работа

В папке `assessment/` находятся:

- мини-тест и ключ преподавателя;
- самостоятельный кейс по обращениям и SLA;
- новый синтетический датасет;
- отдельные student- и teacher-notebooks;
- рубрика на 100 баллов;
- эталонные контрольные значения;

## Финальный контроль качества

Файл `qa/final_qa_report.md` содержит результаты сквозной проверки презентации, notebooks, данных, теста, самостоятельной работы и архивов.

Финальный комплект разделяется на два архива:

- полный преподавательский комплект;
- чистый комплект слушателя без решений, ключей и QA-материалов.
