# Пост-задание к итоговой аналитической работе

## Название

Адаптация учебного проекта под собственный датасет: ETL, EDA, взаимосвязи и подготовка BI-датасета

## Цель

Закрепить практический маршрут итоговой аналитической работы на собственном или выбранном датасете:

```text
выбор данных → описание кейса → загрузка → консолидация → очистка → preprocessing → EDA → статистика → взаимосвязи → подготовка BI-датасета → предварительные выводы
```

После выполнения задания у вас должна появиться первая рабочая версия итогового проекта.

---

## Исходная ситуация

Вы выступаете в роли аналитика данных. Вам нужно выбрать набор данных, подготовить его к анализу, провести первичное исследование, найти основные закономерности и подготовить файл, который позже можно будет использовать в BI-системе для построения дашборда.

Можно использовать:

- собственные данные, если они не содержат персональных, закрытых или конфиденциальных сведений;
- подготовленные учебные данные;
- открытый CSV-датасет, например с Kaggle или другого публичного источника.

## Требования к выбранному датасету

Выберите датасет, который подходит для аналитической работы.

Минимальные требования:

| Критерий | Требование |
|---|---|
| Формат | CSV, XLSX или несколько связанных таблиц |
| Количество строк | желательно от 500 строк |
| Числовые показатели | минимум 2–3 числовых поля |
| Категориальные признаки | минимум 2 категориальных поля |
| Даты | желательно наличие даты события |
| Возможность визуализации | должны быть поля для графиков и срезов |
| Возможность вывода | данные должны позволять сформулировать 3–5 аналитических выводов |

Хороший датасет для итоговой работы должен позволять не только построить график, но и показать очистку, статистику, группировки, взаимосвязи и подготовку данных для BI.

После объединения проверьте:

## Типовые ошибки

| Ошибка | Почему это проблема | Как исправить |
|---|---|---|
| Взят слишком маленький датасет | Нельзя показать полноценный анализ | Выбрать данные с большим количеством строк и признаков |
| Нет описания кейса | Непонятно, зачем выполняется анализ | Заполнить блок постановки задачи |
| Нет проверки качества | Выводы могут строиться на грязных данных | Добавить отчёт по типам, пропускам и дубликатам |
| Очистка сделана без объяснения | Нельзя понять, почему удалены строки | Описать каждое решение preprocessing |
| Построены графики без выводов | Визуализация не превращается в аналитику | После каждого графика написать вывод |
| Корреляция названа причиной | Некорректная интерпретация | Писать «наблюдается связь», а не «доказано влияние» |
| BI-датасет не подготовлен | Нельзя перейти к дашборду | Сохранить чистый файл `outputs/bi_dataset.csv` |
| Выводы слишком общие | Нет аналитической ценности | Привязать выводы к конкретным расчётам |
